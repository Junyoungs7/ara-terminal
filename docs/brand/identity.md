## 1. 마크 방향 4개

### A · 분동과 유리 종 — M3 정직한 기구
- **ARA = 분동(分銅)**: 저울은 속이지 않는다. 기준이 되는 무게 — 꼭지(r 8)·목(폭 10)·몸통(위 50 / 아래 62, 어깨 반경 9). 무게가 아래로 앉는다.
- **Oriel = 유리 종(벨자)**: 안이 다 보이지만 손은 닿지 않는다 — P3 를 물건 하나로. 같은 꼭지 + 수직 옆면 아치(폭 46, 선 9 / 16px 판 14) + 받침(70×8).
- **오독 위험**: ARA — 체스 폰·소화전·병마개. Oriel — **알림 종(벨) 아이콘**(앱 안에서 가장 위험), 음식 덮개. 옆면을 수직으로 세워 벨의 나팔과 갈랐지만 16px 에선 남는다.
- **얼굴**: 말하는 중 = 분동이 저울 위에서 자리를 잡듯 바닥 축 ±4° 흔들림(0.9s).
- 16px: 꼭지·몸통 둘 다 읽힘(16px 전용 판은 꼭지 r 11, 목 14).

### B · 파임 한 획(捺) — M2 먹과 한 획
- **ARA = 파임 획**: 영자팔법의 파임 — 가늘게 들어가(기필 누름) 눌러 내려와 오른쪽으로 펴서 뺀다. 중심선 3차 베지어, 굵기 `w(t)=4+22·t^1.5 + 기필 누름 5·e^-(t/0.06)²`, 끝은 아래 변을 수평으로 18 펴서 뺌.
- **Oriel = 같은 획의 비백(飛白)**: 붓이 마르면 획 안에 종이가 보인다. 획은 그대로, 속이 열린다. 틈 2줄(t≥0.34, 굵기 2.6) / 16px 판 틈 1줄(굵기 6.5).
- **오독 위험**: ARA — **Nike 스우시와 같은 "한 획" 영역**(방향이 오른쪽 아래로 떨어지고 끝이 위로 튀지 않고 납작하게 펴지는 것으로 갈랐다), 깃털·칼날·넥타이 끝. Oriel — 속도선, 깃털.
- **얼굴**: 말하는 중 = 획이 다시 그어진다(clip-path 1.6s) — "지금 쓰는 중".
- 16px: ARA 실루엣 유지, Oriel 은 전용 판(틈 1줄)이어야 읽힘.

### C · 모루와 돌출창 평면도 — M3(도면)

- **판정: 탈락 권고.** 근거가 이름에 가장 가까웠지만 실루엣이 이야기를 못 싣는다.
