# 외부 이미지 생성용 프롬프트 (GPT·Gemini) — ARA · Oriel 브랜드 마크

## 1) 한 쌍 (기본 — 이걸 먼저)

```
Design a pair of brand marks (app icons) for two sibling software products made by the same studio.

PRODUCTS
- ARA: a desktop "integrated development workspace" for software engineers. It holds many tools in one place:
  SSH server terminals, AI coding agents (Claude Code, Codex, Gemini) working side by side with the human,
  a code editor, git review, remote servers. It also has a calm AI companion with a face and voice named "ARA".
  Brand idea: ARA is a UNIVERSE — a quiet, deep space that contains many tools.
- Oriel: a web browser where a human and AI agents look at the same window together. The human always holds
  the steering wheel; AI work is shown as a faint veil, never stealing focus. The name "oriel" means a bay window
  that projects out of a wall — you stay inside the room and look out.
  Brand idea: Oriel is ONE STAR inside ARA's universe. Future tools will be other stars in the same universe,
  so the system must extend (same grammar, different star position/color).

POSITIONING
"Present, not pushy." Tools are honest; the human is the owner.

MOOD
Mix of (a) ink and a single brushstroke — East Asian calligraphy restraint, pressure and release, empty space —
and (b) honest precision instruments — Leica, Braun/Dieter Rams, Teenage Engineering. Calm, deep, crafted.

WHAT I WANT
- A unique, ownable abstract mark at the level of Nike's swoosh, Claude's starburst, Gemini's spark, the OpenAI knot —
  recognizable from its silhouette alone after one look. Do NOT imitate any of those shapes.
- Color is part of the identity (not just black and white), but the mark must still read in one flat color.
- Depth/gradient is welcome at large sizes; it must ALSO have a flat version that stays clear at 16×16 px
  (Windows taskbar, dark #202020 and light #F3F3F3).
- Show: ARA mark and Oriel mark side by side (clearly a family), each at large size; a small-size row (16/24/32 px);
  a macOS-style rounded-square app icon version; and one horizontal lockup with the words "ARA" and "Oriel".

STRICTLY AVOID
- Letters, initials, monograms (no "A", no "O").
- AI clichés: four-point sparkle ✦, glowing orbs/blobs, neural nets, robots, eyes, chat bubbles, magic wands.
- Space clichés: orbit rings, Saturn rings, spiral galaxies, rockets, planets with dots, purple-navy starry sky backgrounds.
- Terminal ">_" symbol, wifi/sonar/radio waves, compass, magnifier, globe, shield, lightning, infinity loop.
- A shape with a "bite" taken out or a detached dot (Apple-like).
- Anything that reads as an everyday object: pie chart, ball, plate, card/photo icon, guitar pick, pebble, bell, weight, food.
- "White glyph on a rounded tile" as the main idea (the tile is only for the macOS variant).
- Neon/lime green; blue-to-pink gradient; purple/magenta as the main brand color.

OUTPUT
A clean presentation board on a warm off-white background, plus the same on near-black.
```

```
Give me 6 clearly different directions for the pair above, each on its own panel with a one-line explanation
of the idea. Vary the core shape language (not just colors). Keep every rule above.
```
