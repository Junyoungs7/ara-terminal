A.R.A 사용 설명서

아라를 처음 켜는 순간부터 서버를 마우스로 다루기까지. 버전 0.1.0 기준입니다.

1. 시작하기

▶ 이 대목을 영상으로 보기

설치

  1. 다운로드에서 설치 파일을 받습니다.
  2. 실행하면 설치 경로를 고르는 화면이 나옵니다. 기본값 그대로 두어도 됩니다.
  3. 설치가 끝나면 바탕화면과 시작 메뉴에 거미 아이콘이 생깁니다.
⚠️ "알 수 없는 게시자" 경고가 뜨면 [추가 정보] → [실행]으로 진행하세요. 아직 코드 서명 전 단계라 나오는 경고입니다. 보안 프로그램이 설치를 막을 때는 다시 시도하지 말고 그 화면을 캡처해 담당자에게 알려 주세요.

첫 실행

처음 켜면 빈 화면에 탭 줄만 있습니다. 탭 줄의 ＋ 를 누르면 로컬 셸(PowerShell)이 열립니다. 서버에 붙으려면 4. 서버에 연결하기로 가세요.

앱을 껐다 켜면 열려 있던 세션과 분할 배치, 작업 폴더가 그대로 복원됩니다. SSH 세션은 비밀번호를 저장해 둔 서버만 자동으로 다시 붙고, 나머지는 [다시 연결] 버튼으로 남습니다.

2. 화면 보는 법

화면은 다섯 자리로 나뉩니다. 어디에 열리는지가 그 기능이 누구 것인지를 말합니다.

  • 맨 위 — 타이틀바: 메뉴(파일·편집·세션·분할·보기·도움말), 가운데 통합 검색, 오른쪽 창 버튼.
  • 왼쪽 — 사이드바: [연결] 탭은 서버 목록, [파일] 탭은 지금 세션의 폴더 트리.
  • 가운데 — 터미널: 탭과 분할이 여기서 일어납니다.
  • 아래 — 하단 패널: 서버의 것(프로세스·서비스·디스크·패키지·컨테이너·포트·시스템·세션 기록).
  • 오른쪽 — 아이콘 바: 아라의 것(AI 대화·AI 세션·지난 기록·미니 프리뷰). 한 번에 하나만 열립니다.

맨 아래 상태 표시줄에는 지금 붙어 있는 호스트, 작업 폴더, 세션 개수, 인코딩, 버전이 있습니다.

💡 같은 아이콘을 다시 누르면 닫힙니다. 사이드바는 Ctrl+Shift+B 로도 접힙니다.

3. 세션 · 탭 · 창

▶ 이 대목을 영상으로 보기

새 세션

탭 줄의 ＋ 또는 Ctrl+Shift+T. ＋ 옆 화살표를 누르면 로컬 셸·저장해 둔 서버·AI CLI 시작을 골라 열 수 있습니다.

분할

Ctrl+Shift+\ 로 세로 분할, Ctrl+Shift+- 로 가로 분할합니다. 칸 사이는 Alt+방향키로 옮겨 다니고, Ctrl+↑ 로 지금 칸을 잠깐 최대화합니다. 칸을 클릭하면 탭과 왼쪽 파일 트리도 그 세션 것으로 따라옵니다.

탭을 창 밖으로

탭을 잡아 아라 창 바깥 어디로든 끌어다 놓으면 새 창이 됩니다(크롬과 같습니다). 반대로 새 창의 탭을 본창 탭 줄에 끌어다 놓으면 돌아옵니다. 세션은 끊기지 않고 그대로 옮겨집니다.

세션이 살아 있는 창을 닫으려 하면 [본창으로 보내기]와 [세션 종료]를 묻습니다. 실수로 작업을 날리지 않게 하는 자리입니다.

tmux

SSH 세션에서 탭이나 터미널을 우클릭하면 tmux 항목이 나옵니다. 실행 중인 세션 목록에서 골라 붙거나 이름을 정해 새로 만듭니다. tmux 가 없는 서버에서는 항목이 잠기고 설치 안내가 나옵니다.

4. 서버에 연결하기

▶ 이 대목을 영상으로 보기

연결 프로필 만들기

  1. 왼쪽 사이드바 [연결] 탭에서 ＋ 를 누릅니다(또는 Ctrl+Shift+M 연결 관리자).
  2. 연결 이름 · 호스트 · 포트 · 사용자를 넣습니다. 그룹을 정하면 트리에서 묶여 보입니다.
  3. 인증은 비밀번호나 공개키를 고릅니다.
  4. [접속 테스트]로 확인한 뒤 [저장 후 접속].

저장한 서버는 트리에서 더블클릭하면 새 세션으로 접속합니다. 한 번 클릭은 선택, 펼치면 그 서버에 열려 있는 세션이 보입니다.

호스트 키 확인

처음 붙는 서버는 지문(SHA256)을 보여 주고 확인을 받습니다. 예상과 같은지 보고 신뢰하면 다음부터 묻지 않습니다. 나중에 지문이 달라지면 접속을 멈춥니다 — 서버를 새로 설치한 게 아니라면 관리자에게 확인하세요.

비밀번호는 어디에 저장되나

비밀번호와 개인키 암구호는 Windows 자격 증명에 들어갑니다. 설정 파일 (workspace.json)에는 저장되지 않습니다. 저장해 두지 않은 서버는 접속할 때마다 물어보고, 그 값은 그 접속에만 씁니다.

5. 파일 다루기

▶ 이 대목을 영상으로 보기

왼쪽 파일 트리

셸을 열면 사이드바가 [파일] 탭으로 넘어가면서 지금 폴더를 보여 줍니다. 터미널에서 cd 하면 트리도 따라 움직입니다(원격도 마찬가지). Ctrl+Shift+E 로 열고 닫습니다.

서버 작업대 (탐색기 창)

Ctrl+Shift+O 를 누르면 폭이 넓은 작업대 창이 뜹니다. 왼쪽 트리보다 할 수 있는 일이 많습니다.

  • 탭 여러 개로 서버·폴더를 나란히 열기
  • 업로드 · 다운로드 · 서버 ↔ 서버 복사(끌어다 놓기)
  • 새 폴더 · 이름 바꾸기 · 복사 · 잘라내기 · 삭제(확인을 거칩니다)
  • 이름으로 거르기, 뒤로 · 앞으로

텍스트 파일은 더블클릭하면 열립니다. 고쳐서 저장하면 그대로 서버에 올라갑니다. 큰 파일이나 바이너리는 열지 않고 안내합니다.

💡 전송은 진행률이 보이고, 끊긴 전송은 이어받기를 시도합니다. 창을 닫아도 전송은 계속됩니다.

6. 서버를 마우스로

▶ 이 대목을 영상으로 보기

SSH 세션에서 오른쪽 아이콘 바의 도구를 누르면 화면 아래에 표가 펼쳐집니다. 표 오른쪽 위에 어느 서버 것인지가 항상 찍혀 있습니다. 세션 탭을 다른 서버로 바꾸면 표도 그 서버 것으로 따라옵니다.

하단 패널의 도구
프로세스PID · 사용자 · CPU · 메모리 · 명령. 정렬 · 검색 · 종료(확인 후).
서비스systemd 유닛과 상태. 시작 · 정지 · 재시작. systemd 가 없으면 안내가 나옵니다.
디스크파일시스템 사용량 → 폴더로 파고들기 → [뒤로]. 큰 폴더 찾기에 씁니다.
패키지설치된 패키지 목록(배포판별 도구를 알아서 고릅니다).
컨테이너도커 컨테이너 목록. 런타임이 없으면 그렇게 알려 줍니다.
포트 모니터열린 포트와 프로세스. 원격 포트를 내 PC로 당겨오는 포워딩도 여기서.
시스템 모니터CPU · 메모리 · GPU · 네트워크 실시간 그래프.
세션 기록지금 세션에서 실행한 명령과 그 결과.
🛑 바꾸는 작업은 반드시 확인을 거칩니다. 종료할 프로세스나 다룰 서비스의 이름을 문구에 박아 보여 주고, 실패하면 서버가 준 이유(권한 부족 등)를 그대로 보여 줍니다. sudo 는 붙이지 않습니다.

7. AI에게 묻기

▶ 이 대목을 영상으로 보기

준비

Ctrl+, → [AI] 에서 프로바이더를 고르고 API 키를 넣습니다. 사내 vLLM 처럼 자체 서버를 쓸 때는 [호환 엔드포인트]를 골라 주소와 모델 이름을 넣습니다.

🔑 API 키는 앱의 입력창에만 넣으세요. 채팅·문서·코드에 붙여넣지 마세요. 키는 Windows 자격 증명에 저장되고 설정 파일에는 남지 않습니다.

대화

Alt+A 로 오른쪽 대화창을 엽니다. 터미널에서 글자를 선택하고 우클릭 → [AI에게 질문]을 고르면 그 내용이 질문에 담깁니다(Ctrl+Shift+A).

  • 컨텍스트 칩으로 무엇을 함께 보낼지 고릅니다(선택한 출력 · 현재 폴더 · 세션 기록 등).
  • 보내기 전에 비밀번호·토큰처럼 보이는 값은 •••• 로 가립니다. 첨부 배지를 누르면 실제로 보낸 내용을 볼 수 있습니다.
  • 답이 길어지면 [중지]로 끊을 수 있고, 아래에 사용한 토큰이 표시됩니다.
  • 대화가 길어지면 오래된 부분을 빼고 보낸 뒤 그 사실을 알려 줍니다.

명령은 넣기만 합니다

답에 들어 있는 명령 상자에는 [터미널로 보내기] 버튼이 있습니다. 누르면 명령이 프롬프트에 들어가기만 합니다. 실행은 사람이 Enter 를 눌러야 일어납니다.

AI CLI 한 번에 시작

Ctrl+Shift+L 로 서버 · 폴더 · CLI(claude · codex · gemini)와 옵션을 한 화면에서 고르고 시작합니다. 폴더가 없으면 만들어 주고, 실제로 보낼 명령을 미리 보여 줍니다. 한 번 쓴 조합은 최근 목록에 남아 다음부터는 한 번에 시작됩니다.

8. 링크 · 포트 · 브라우저

터미널에 찍힌 주소는 Ctrl+클릭으로만 열립니다(그냥 클릭으로는 열리지 않습니다).

Ctrl+클릭원격 세션의 주소면 아라 브라우저로 엽니다. localhost 주소는 터널을 자동으로 뚫어 내 PC에서 볼 수 있게 합니다.
Ctrl+Alt+클릭내 PC의 기본 브라우저(크롬 등)로 보냅니다. 즐겨찾기나 로그인 세션이 있는 쪽에서 열고 싶을 때.

원격 CLI 로그인처럼 콜백 포트가 필요한 주소는 어떤 포트를 여는지 먼저 보여 주고 확인을 받은 뒤에 터널을 만듭니다. 아라 브라우저는 앱과 분리된 저장 공간에서 돌고 파일 다운로드와 새 창 띄우기를 막아 둡니다.

9. 세션 기록

세션마다 주고받은 내용이 파일로 남습니다. 비밀번호·토큰으로 보이는 값은 가려서 기록하고, vim·htop 같은 전체 화면 프로그램의 화면 갱신은 남기지 않습니다.

  • 하단 [세션 기록] — 지금 세션의 명령과 결과
  • 오른쪽 [지난 기록] — 지난 세션 목록. 진행 중인 것을 누르면 하단으로 보냅니다
  • 보존 기간(7 · 30 · 90일 · 무제한)과 기록이 쌓이는 폴더는 설정 → [로그]에서 정합니다

12. 업데이트

아라는 실행 중에 사내 배포 서버를 조용히 확인합니다. 새 버전이 있으면 뒤에서 받아 두고, 앱을 껐다 켤 때 적용합니다. 쓰던 작업이 끊기지 않습니다.

  • 설정 → [일반] → 업데이트에서 지금 버전과 상태를 봅니다.
  • [업데이트 확인]으로 즉시 확인할 수 있습니다.
  • 내려받기가 끝나면 [다시 시작하여 설치] 버튼이 생깁니다. 눌러도 되고, 그냥 두었다가 다음에 켤 때 적용해도 됩니다.
🌐 업데이트를 받아 오는 곳은 이 사이트와 같은 자리입니다 — http://192.168.100.56:8899/downloads/. 사내망 밖(집·외부 테더링)에서는 확인이 실패하고 확인하지 못했습니다로 표시됩니다. 앱 사용에는 지장이 없습니다.

13. 문제 해결

접속이 안 됩니다

  • 실패하면 서버가 준 응답을 그대로 보여 줍니다. 그 문구를 먼저 보세요.
  • 비밀번호가 바뀐 서버는 [비밀번호 다시 입력]으로 갱신합니다.
  • 호스트 키 경고가 뜨면 접속을 강행하지 말고 관리자에게 확인하세요.

한글이 깨집니다

아라는 한글 고정폭 폰트를 함께 담고 있어 서버에 폰트가 없어도 깨지지 않습니다. 그래도 어긋나면 설정 → [폰트]에서 다른 후보를 골라 같은 문장으로 비교해 보세요. 서버 쪽 로캘(LANG)이 UTF-8 인지도 확인하세요.

화면 글자가 작습니다

설정 → [일반] → UI 글자 크기. 터미널 글자 크기는 [폰트]에서 따로 정합니다.

파일 트리가 안 따라옵니다

서버에 /proc 이 없거나 셸이 특수한 경우 현재 폴더를 자동으로 읽지 못합니다. 그럴 때는 안내가 뜨고, 트리의 새로고침으로 맞출 수 있습니다.

기록을 확인하고 싶습니다

설정 → [로그] → [폴더 열기]. 문제가 생겼을 때 담당자에게 보낼 진단 기록은 같은 화면의 앱 로그 폴더에 있는 main-error.log 입니다.
