- **게이트**: `npm run scan:magic` 이 shell.css·interactions.css 의 `--accent*` 를 쓰는 규칙을 선택자 이름으로 이 표와 대조한다(`ACCENT_OK`). 표에 자리를 더하면 그 목록도 같이 고친다. TSX 인라인 색(BrandOrb 마크·터미널 검색 강조)은 못 본다.
- 그 밖의 선택 행·호버·활성 라벨·드롭 자리·리사이저·배지는 **중성**이다 — 선택 = 글라스(`--glass` + 위 1px `--glass-hi`), 활성 글자 `--text-hi`, 호버 테두리 `--text-lo`, 끌어 놓기 자리 2px 점선 `--text-mid`.
- **AI 전용 색은 없다.** 1.x 의 보라(`--purple`)는 2.0 다듬기 R2 에서 지웠다 — 채팅·MCP·AI 표면도 중성이고, 메모리 그래프는 `--accent-bright` 다. (터미널 ANSI magenta `--t-purple*` 는 터미널 팔레트라 별개다.)

분할 창 활성 표시에는 **쓰지 않는다**(탭 밑줄과 겹쳐 취소됨) — 비활성 창을 `rgba(0,0,0,.22)` 로 어둡게만.

## 2. 글자

- **굵기는 400 / 500 두 개.** 본문 400, 강조(채팅 대상·경로의 활성 칸·제목) 500. **600 은 브랜드 `A.R.A` 한 곳만.**
- 크기: **13px** 본문·탭·터미널 · **12px** 보조(상태바·사이드바 탭·그룹 라벨·툴팁·버튼) · **11px** 꼬리표(단축키 kbd·행 오른쪽 값·사용량 줄) · 제목 15~16px(설정 창 머리 등, 화면마다 한 곳).
- 자간: 13px 이상 `0`, **11~12px 는 `.01em`**.
- 줄 높이: UI 1.45 · 터미널 1.55 · 말풍선 1.6.
- 글꼴: UI `Pretendard` · 터미널 `--term`(사용자 설정) — 1.x 그대로.
- 숫자가 바뀌는 자리(상태바·사용량·kbd)는 `font-variant-numeric: tabular-nums`.
- **단축키 칩은 공용 `.kbd` 하나**(다듬기 R1): UI 글꼴(고정폭 아님) 11/400 · `--bg-raised` 면 + 1px `--line` · 반경 4 · 키 사이 공백(`Ctrl Shift K`, `+` 없음 — `keyText()`). 타이틀바·설정·빈 화면·통합 검색·툴팁·치트시트·우클릭 메뉴가 같은 모양이다.

| 자리 | 반경 |

| 세션 창·탭·패널·타이틀바·사이드바 | **0** (각진 면) |

## 4. 같은 높이 규칙

| 줄 | 높이 |
|---|---|
| 타이틀바 | 40px |
| **탭바 = 채팅 머리 = 사이드바 머리(탭 줄)** | **38px** — 세 머리가 한 선에 맞는다 |
| 상태바 | 28px |
| 사이드바 행 | 28px |
| 레일 폭 / 사이드바 폭 / 채팅 폭 | 44 / 232 / 348px |

1단계에서는 높이 토큰(`--row-titlebar` 36 · `--row-tabbar` 32 · `--row-statusbar` 26)을 **바꾸지 않았다** — 레이아웃은 2단계.
