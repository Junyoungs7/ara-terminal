# 아라 플러그인 표준 (P0)

사내 웹 시스템을 **아라 안에서 열리게** 등록하는 방법. 다른 팀 개발자가 읽는 문서다.

배경과 설계 근거는 `docs/plan-plugin-market.md` 에 있다 — 여기는 **무엇을 하면 되는가**만 적는다.

---

## 0. 한 줄

> 서버에 서비스를 띄우고 → 확인용 경로 하나를 열고 → `registry.json` 에 PR 을 넣으면,
> 아라 사이드바에 버튼이 생기고 아라 브라우저에서 열린다.

---

## 1. 조건 셋

### ① 서비스는 **배포 서버 위**에서 돈다

`192.168.100.56` 에서 돌아야 한다. 개발자 PC 에서 돌리면 **PC 를 끄는 순간 죽고**,
방화벽이 막아 주지 않아 아라를 통하지 않고도 닿는다 — 그러면 이 체계의 이유가 없어진다.

### ② 포트는 **3000~3999** 를 쓴다

- 🔴 **8000~9000 을 쓰지 않는다.** 그 대역은 개발자 PC 에서 직접 닿는 대역이고,
  거기 띄우면 아라를 통하지 않고 접속할 수 있어 등록할 이유가 없다.
- 3000~3999 는 다른 PC 에서 **막혀 있다.** 아라 프록시만이 길이다 — 그것이 이 설계의 전부다.
- ⚠️ 이 대역 밖은 **등록 자체가 거절된다**(22·3306·5432·2375 같은 것을 프록시에 매달지 못하게).

### ③ 확인용 경로 하나를 연다 — `GET /.well-known/ara-verify`

등록할 때 발급받은 토큰을 **그대로** 돌려주면 된다. 본문만 맞으면 형식은 상관없다.

```js
// express 예시 — 이 세 줄이 전부다
app.get('/.well-known/ara-verify', (_req, res) =>
  res.type('text/plain').send(process.env.ARA_VERIFY_TOKEN)
)
```

**왜 필요한가**: 이게 없으면 누구나 아무 포트(SSH·DB·도커 API)를 프록시에 매달 수 있다.
"그 포트가 정말 당신의 웹 서비스인가"를 확인하는 유일한 방법이다.

⚠️ **끄지 마라.** 등록 후에도 아라가 주기적으로 이 경로를 쳐서 **살아 있는지**를 본다.
응답이 없으면 사이드바에 **꺼짐**으로 표시된다(눌렀는데 빈 화면이 뜨는 것보다 낫다).

## 2. 등록하는 법

1. 위 조건 셋을 갖춘다
2. `site/plugins/registry.json` 에 항목 하나를 더해 **PR** 을 올린다(아래 §3)
3. 검토 후 병합되면 **프록시 포트가 배정되고**(8000~9000 중 하나) 라우트가 생긴다
4. 다음 배포부터 아라 사이드바에 뜬다

> 자율 등록 화면(P2)은 나중에 붙는다. 형식은 지금과 같으므로 그때 다시 쓸 일은 없다.

## 3. 매니페스트

```jsonc
{
  "id": "vgt-erp-admin",        // 고유. [a-z0-9-] 만. 저장소 키가 여기서 파생된다
  "name": "ERP 관리자",          // 사이드바·탭에 뜨는 이름
  "icon": "erp.svg",            // site/plugins/icons/ 에 함께 올린다. 없으면 기본 아이콘
  "publisher": "개발1팀",        // 문제가 생겼을 때 물어볼 곳
  "kind": "web",                // web | external (§5)
  "group": "업무",               // 사이드바 묶음
  "target": "localhost:3000",   // 🔴 프록시가 보낼 곳. **당신이 띄운 포트**
  "path": "/admin",             // 기본으로 열 경로(없으면 "/")
  "minAraVersion": "1.3.0"
}
```

**아라가 채우는 것**(PR 에 적지 않는다): `port`(배정된 프록시 포트) · `url`(그로부터 조립) ·
`origins` · `verifyToken`.

### `registry.json`

```jsonc
{ "version": 1, "plugins": [ /* 위 항목들 */ ] }
```

## 4. 🔴 아라 안에서 도는 웹이 지켜야 하는 것

아라 브라우저는 **일반 크롬이 아니다.** 아래를 모르고 만들면 배포 후에 깨진다.

| | 아라에서 | 무엇을 하면 되나 |
|---|---|---|
| **다운로드** | ✅ **된다** — 저장 위치를 묻는 창이 뜬다 | 그대로 쓰면 된다 |
| **`window.open` 팝업** | 창이 아니라 **새 탭**으로 열린다 | 그대로 쓰면 된다. `window.opener` 로 부모를 조작하는 방식은 피한다 |
| **인쇄** | ✅ 된다 | — |
| **카메라·마이크·위치·알림·USB·시리얼** | ❌ **전부 거부** | 쓰지 않는다. 필요하면 먼저 이야기해 달라 |
| **`file://`·`ms-msdt:` 등 http 아닌 스킴** | ❌ 차단 | 로컬 파일을 직접 열게 하지 않는다 |
| **자체 서명 인증서(https)** | ❌ 연결 거부 | 사내 CA 로 정식 발급받거나 http 를 쓴다 |
| **`window.ev` 같은 아라 API** | ❌ **없다** | 아라는 플러그인에 아무것도 주지 않는다. 필요한 것은 **당신의 서버**에서 받는다 |

### 알아 둘 것 둘

- **쿠키는 플러그인끼리 공유된다.** 프록시가 같은 호스트의 다른 포트로 갈라 주는데,
  쿠키는 포트를 무시하기 때문이다. **SSO 는 한 번만 로그인하면 되고**(편하다),
  대신 다른 플러그인이 같은 쿠키를 갖는다. `localStorage` 는 갈린다.
- **절대경로(`/static/…`)를 그대로 써도 된다.** 포트마다 당신의 서비스가 **루트에 앉는다.**

## 5. Electron 으로 만든 앱이라면

🔴 **Electron 앱은 아라 안에 못 넣는다.** 남이 만든 Node 코드를 아라의 권한으로 돌리는 일이라,
아라가 지켜 온 경계가 한 번에 무효가 된다. 대신:

| 상황 | 하면 되는 것 |
|---|---|
| **대부분** | Electron 앱의 **화면은 이미 웹이다.** 그 렌더러를 서버에 띄우고 `ipcRenderer` 쓰던 자리를 당신 서버의 API 로 바꾸면 **그 순간 `kind:web`** 이다 |
| 파일 접근·네이티브 모듈이 **꼭** 필요 | 그 부분만 서버로 뺀다. 화면은 위와 같다 |
| 도저히 안 된다 | `kind: "external"` 로 등록한다. 아라가 **띄워만 주고**, 목록에 *"아라 밖에서 열립니다"* 라고 적힌다 |

---

## 6. 올리기 전 확인

- [ ] 서비스가 **배포 서버**에서 돈다(내 PC 아님)
- [ ] 포트가 **3000~3999**
- [ ] `curl localhost:<포트>/.well-known/ara-verify` 가 토큰을 돌려준다
- [ ] 서버가 재부팅돼도 서비스가 **다시 뜬다**(systemd·docker `--restart`)
- [ ] 카메라·마이크·위치·알림을 **안 쓴다**
- [ ] https 라면 인증서가 **정식 발급본**이다

## 부록 — 아라 쪽이 P1 에서 해야 하는 일 (우리 몫)

| | 무엇 | 왜 |
|---|---|---|
| 1 | `hardenPluginSession()` — `hardenSession` 을 베끼되 **다운로드를 허용**한다 | 지금 파티션은 OAuth·미리보기용이라 `will-download` 를 전면 차단한다(`BrowserService.ts:37`). 사내 ERP 는 **엑셀을 내려받는다** — 그 주석이 *"실제 요구가 나오면 저장 대화상자 경유로 승격한다"* 고 예고해 뒀다 |
| 2 | `setWindowOpenHandler` 를 **새 탭**으로 | 지금은 보던 탭을 갈아치운다. 사내 결재 팝업에서 거부보다 나쁘다 |
| 3 | 탭·사이드바 라벨에 **레지스트리 이름** 사용 — 단 선언한 오리진 안에 있을 때만 | 이름의 출처가 페이지가 아니라 검토된 레지스트리다. 벗어나면 오리진 표기로 떨어뜨려 위장을 막는다 |
| 4 | 프록시 호스트로 가는 요청에만 `X-ARA-Token` 을 붙인다(호스트를 **콜백에서** 확인) | 매치 패턴에 맡기면 토큰이 남의 사이트로 샌다 |
| 5 | 사이드바 [플러그인] 목록 + 켜짐/꺼짐 점 | `/.well-known/ara-verify` 재사용 |
| 6 | 🔴 `:8899/` 와 `/downloads/` 는 **토큰 없이** 연다 | 아라가 없는 PC 가 크롬으로 받으러 온다(닭과 달걀). `electron-updater` 도 그 헤더를 안 보낸다 |
