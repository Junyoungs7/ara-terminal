1. 시작하기

설치

  1. 다운로드에서 설치 파일을 받습니다.
  2. 실행하면 설치 경로를 고르는 화면이 나옵니다. 기본값 그대로 두어도 됩니다.
  3. 설치가 끝나면 바탕화면과 시작 메뉴에 아라 아이콘(터미널 창 둘레를 고리가 도는 마크)이 생깁니다.
⚠️ "알 수 없는 게시자" 경고가 뜨면 [추가 정보] → [실행]으로 진행하세요. 아직 코드 서명 전 단계라 나오는 경고입니다. 보안 프로그램이 설치를 막을 때는 다시 시도하지 말고 그 화면을 캡처해 담당자에게 알려 주세요.

첫 실행

처음 켤 때는 두 가지가 먼저 지나갑니다.

  1. 부팅 인사 — 짧게 지나갑니다. 아무 키나 누르면 바로 건너뜁니다. 매번 보고 싶지 않으면 설정 → [일반] → [켤 때 인사 화면] 에서 끕니다.
  2. [처음 뵙겠습니다] — 뭐라고 불러 드릴지 딱 한 번 묻습니다. [나중에]로 건너뛰어도 되고, 건너뛰면 다시 묻지 않습니다. 나중에 정하거나 바꾸려면 설정 → [AI] → [아라가 부를 이름].

그 뒤에 빈 화면과 탭 줄이 나옵니다. 탭 줄의 ＋ 를 누르면 로컬 셸(PowerShell)이 열립니다. 서버에 붙으려면 4. 서버에 연결하기로 가세요.

앱을 껐다 켜면 열려 있던 세션과 분할 배치, 작업 폴더가 그대로 복원됩니다. SSH 세션은 비밀번호를 저장해 둔 서버만 자동으로 다시 붙고, 나머지는 [다시 연결] 버튼으로 남습니다.

ℹ️ 복원되는 것은 로컬 셸과 SSH 세션입니다. 원격 데스크톱(RDP) 탭은 복원되지 않습니다 — 다시 켠 뒤 서버 트리에서 다시 붙어야 합니다(§7.5).

2. 화면 보는 법

화면은 다섯 자리로 나뉩니다. 어디에 열리는지가 그 기능이 누구 것인지를 말합니다.

  • 맨 위 — 타이틀바: 메뉴(파일·편집·세션·분할·보기·도움말), 가운데 통합 검색, 오른쪽 창 버튼.
  • 왼쪽 — 사이드바: 탭 셋입니다. [연결] 은 서버 목록, [파일] 은 지금 세션의 폴더 트리, [AI 세션] 은 지금 어느 AI 가 무엇을 하는지.
  • 가운데 — 터미널: 탭과 분할이 여기서 일어납니다. 원격 데스크톱 화면도 여기 탭으로 뜹니다.
  • 아래 — 하단 패널: 서버의 것. 도구 열 개가 여기 탭으로 섭니다(§6).
  • 오른쪽 — 아이콘 바: 아라의 것.

오른쪽 아이콘 바는 성격이 다른 셋이 한 줄에 있습니다.

  • 옆에 붙는 패널 셋 — [아라](대화) · [지난 세션] · [미니 프리뷰]. 이 셋만 한 번에 하나 열립니다(터미널의 폭을 나눠 쓰기 때문입니다).
  • 창·오버레이를 여는 버튼 셋 — [서버 작업대] · [명령어 북] · [설정]. 이것들은 따로 뜨므로 "한 번에 하나" 규칙 밖입니다.
  • 맨 아래 하단바 토글 — 아래 도구 패널을 통째로 여닫습니다.

맨 아래 상태 표시줄

지금 붙어 있는 호스트, 작업 폴더, 세션 개수, 인코딩, 버전이 있고, 거기에 더해

  • CPU · 메모리 그래프 — 지금 보고 있는 서버의 실시간 사용량입니다.
  • [AI 조종 중] — 아라나 외부 AI 클라이언트가 이 앱의 도구를 쓰고 있을 때 켜집니다.
  • 오른쪽 끝 아이콘 줄 — 하단 도구 열 개를 여는 주 진입점입니다. 누르면 그 도구가 아래에 펼쳐집니다.

세션 점의 색

탭, 분할 칸의 머리, 미니 프리뷰에 작은 점이 붙습니다. 세 자리 모두 같은 점이고, 말하는 것도 한 가지입니다 — 연결 상태입니다. 서버마다 다른 색을 쓰지 않습니다.

초록켜짐 — 세션이 살아 있습니다
노랑연결 중… — 아직 붙지 않았습니다
빨강끊김 — 연결이 끊어졌습니다
💡 점은 아주 작아서 색만으로는 구별하기 어려울 수 있습니다. 마우스를 올리면 위 문장이 글자로 그대로 뜹니다 — 헷갈릴 때는 색을 노려보지 말고 올려 보세요. 사이드바 [AI 세션] 목록의 점은 뜻이 다릅니다(§8.3).
💡 같은 아이콘을 다시 누르면 닫힙니다. 사이드바는 Ctrl+Shift+B 로도 접힙니다.

3. 세션 · 탭 · 창

새 세션

탭 줄의 ＋ 또는 Ctrl+Shift+T. ＋ 옆 화살표를 누르면 로컬 셸·저장해 둔 서버·AI CLI 시작을 골라 열 수 있습니다.

분할

Ctrl+Shift+\ 로 세로 분할, Ctrl+Shift+- 로 가로 분할합니다. 칸 사이는 Alt+방향키로 옮겨 다니고, Ctrl+↑ 로 지금 칸을 잠깐 최대화합니다. 칸을 클릭하면 탭과 왼쪽 파일 트리도 그 세션 것으로 따라옵니다.

탭을 창 밖으로

탭을 잡아 아라 창 바깥 어디로든 끌어다 놓으면 새 창이 됩니다(크롬과 같습니다). 반대로 새 창의 탭을 본창 탭 줄에 끌어다 놓으면 돌아옵니다. 세션은 끊기지 않고 그대로 옮겨집니다. 떼어낸 창은 앞으로 올라옵니다.

세션이 살아 있는 창을 닫으려 하면 [본창으로 보내기]와 [세션 종료]를 묻습니다. 실수로 작업을 날리지 않게 하는 자리입니다.

⚠️ 원격 데스크톱(RDP) 탭만은 창 밖으로 뗄 수 없습니다. 끌면 "원격 데스크톱(RDP) 탭은 창을 분리할 수 없습니다 — 이 창에서만 볼 수 있습니다" 가 뜹니다. 이유는 §7.5 에 적어 두었습니다.

탭을 ✕ 로 닫거나 창 밖으로 떼어내면, 다음에 보이는 것은 가장 최근에 보던 탭입니다 (VS Code 와 같습니다 — 브라우저처럼 오른쪽 탭으로 가지 않습니다).

tmux

SSH 세션에서 탭이나 터미널을 우클릭하면 tmux 항목이 나옵니다. 실행 중인 세션 목록에서 골라 붙거나 이름을 정해 새로 만듭니다. tmux 가 없는 서버에서는 항목이 잠기고 설치 안내가 나옵니다.

4. 서버에 연결하기

4.1 연결 프로필 만들기

  1. 왼쪽 사이드바 [연결] 탭에서 ＋ 를 누릅니다(또는 Ctrl+Shift+M 연결 관리자).
  2. 맨 위에서 [SSH] / [RDP] 를 고릅니다. 고르면 포트도 따라 바뀝니다(SSH 22 · RDP 3389). 직접 넣은 포트는 건드리지 않습니다. RDP 는 §7 로.
  3. 연결 이름 · 호스트 · 포트 · 사용자를 넣습니다. 그룹을 정하면 트리에서 묶여 보입니다.
  4. SSH 인증은 비밀번호나 공개키를 고릅니다.
  5. [접속 테스트]로 확인한 뒤 [저장 후 접속].

저장한 서버는 트리에서 더블클릭하면 새 세션으로 접속합니다. 한 번 클릭은 선택, 펼치면 그 서버에 열려 있는 세션이 보입니다.

4.2 호스트 키 확인

처음 붙는 서버는 지문(SHA256)을 보여 주고 확인을 받습니다. 예상과 같은지 보고 신뢰하면 다음부터 묻지 않습니다. 나중에 지문이 달라지면 접속을 멈춥니다 — 서버를 새로 설치한 게 아니라면 관리자에게 확인하세요.

4.3 비밀번호는 어디에 저장되나

비밀번호와 개인키 암구호는 Windows 가 잠가 보관합니다. 설정 파일 (workspace.json)에는 저장되지 않고, 잠글 수 없는 환경이면 저장 자체를 거부합니다 — 평문으로 남기느니 안 남깁니다. 저장해 두지 않은 서버는 접속할 때마다 물어보고, 그 값은 그 접속에만 씁니다.

4.4 서버에 남는 것 — AI 상태 훅

아라는 원격 서버에 프로그램을 설치하지 않습니다. 상주하는 에이전트도, 데몬도, 패키지도 없습니다. 다만 두 가지는 남깁니다 — 붙어 있는 동안의 통로 하나와, Claude Code 가 있는 서버라면 설정 파일 한 줄. 감추지 않고 여기 적어 둡니다.

① 붙어 있는 동안의 통로 — 붙는 서버 전부

SSH 로 붙으면 그 연결 안에 되돌아오는 길을 하나 엽니다. 서버가 우리에게 한 마디를 보낼 수 있어야 하기 때문입니다. 서버의 127.0.0.1 에만 열려 밖에서는 닿을 수 없고, 세션을 닫으면 함께 사라집니다. 남는 파일도 없습니다.

ℹ️ 관리자가 ss -tlnp 로 보면 이 포트는 보입니다. 그리고 아래 ② 를 건너뛴 서버(Claude Code 가 없는 서버)에도 이 통로만은 열립니다 — 그쪽에 파일을 안 만든다고 해서 아무 흔적도 없는 것은 아니라는 뜻입니다. 서버가 AllowTcpForwarding no 로 막아 두었다면 통로가 안 열리고, 그러면 ② 도 아예 하지 않습니다.

② 설정 파일 한 줄 — ~/.claude 가 있는 서버만

사이드바 [AI 세션] 목록이 "지금 이 서버의 claude 가 일하는 중인지, 나를 기다리는 중인지"를 말하려면, 그 CLI 가 직접 알려 주어야 합니다. 그래서 SSH 로 붙을 때 그 서버의 ~/.claude/settings.json 에 훅 한 줄을 얹습니다. 이미 있던 훅은 그대로 두고 우리 것만 더합니다.

그 한 줄은 상주하는 프로세스가 아닙니다. claude 가 "일을 시작했다 · 사람을 기다린다 · 한 턴을 끝냈다" 를 알릴 때 그때 한 번 불려서, 이 세션으로 돌아오는 길(그 SSH 연결 안의 되돌아오는 통로)로 짧게 알리고 곧바로 끝납니다. 길을 못 찾으면 아무 일도 하지 않고 조용히 끝냅니다 — 무슨 일이 있어도 셸을 멈춰 세우지 않습니다.

남는 파일은 최대 셋

~/.claude/settings.json훅 한 줄이 합쳐집니다. 원래 있던 내용은 그대로입니다.
~/.claude/settings.json.bak되돌릴 사본입니다. 원래 settings.json 이 있던 서버에 맨 처음 심을 때 한 번 만듭니다(그 파일이 없던 서버라면 새로 만들 뿐이라 사본도 없습니다).
~/.claude/ara-tty-…알릴 길을 찾기 위한 한 줄짜리 쪽지 파일입니다(서버 설정을 고치지 않아도 되게 하는 우회로).

~/.claude 폴더가 없는 서버에는 아무것도 만들지 않습니다 — 폴더도, 파일도. Claude Code 를 쓰지 않는 서버로 보고 건너뜁니다.

끌 수 있나

지금은 끄는 스위치가 없습니다. SSH 로 붙을 때마다 심어 봅니다. 굳이 막아야 하는 서버라면 그 서버에서 ~/.claude 를 없애면(= Claude Code 를 안 쓰는 서버가 되면) 건너뜁니다.

어디서 확인하나

설정 → [AI] → [원격 상태 훅]. 붙어 본 서버를 한 줄씩 결과와 함께 보여 줍니다 — 심겼습니다 · 건너뛰었습니다(~/.claude 가 없음) · 심지 못했습니다(사유 그대로). 내 PC 쪽은 바로 위 [상태 훅] 행이 같은 방식으로 말합니다.

일부 서버는 "이 서버는 sshd 에 AcceptEnv ARA_HOOK_PORT ARA_PANE 한 줄이 필요합니다" 라고 나옵니다. 알릴 길을 스스로 찾지 못하는 서버라는 뜻입니다 — 그 한 줄을 넣어 달라고 관리자에게 요청하면 됩니다.

되돌리려면

앱에는 지우는 기능이 없습니다. 손으로 지웁니다 — settings.json 에서 우리 줄을 빼거나 settings.json.bak 으로 되돌리고, 남은 ara-tty-… 파일을 지우면 됩니다.

ℹ️ ara-tty-… 는 일부러 남겨 둡니다. 앱을 끈 뒤에 그 파일이 남아 있어도 가리키는 곳이 이미 없어서 훅이 즉시 포기하고 끝날 뿐이고, 같은 자리를 다시 쓰는 세션이 그 파일을 덮어씁니다. 지우고 다시 만들기를 반복하는 것보다 조용합니다.

이걸 안 하면 무엇을 잃나

잃는 것은 AI 상태 표시 하나뿐입니다. 그 서버의 AI 는 [AI 세션] 목록에서 [확인 불가] 로 남고, "나를 기다립니다" 알림이 오지 않습니다. 나머지는 전부 그대로 됩니다 — 접속 · 터미널 · 파일 전송 · 서버 도구 · 포트 포워딩 · AI CLI 실행 모두 훅과 무관합니다.

5. 파일 다루기

왼쪽 파일 트리

셸을 열면 사이드바가 [파일] 탭으로 넘어가면서 지금 폴더를 보여 줍니다. 터미널에서 cd 하면 트리도 따라 움직입니다(원격도 마찬가지). Ctrl+Shift+E 로 열고 닫습니다.

트리에서 파일을 우클릭하면 편집 · 다운로드 · 이름 변경 · 새 폴더 · 삭제와 함께 [서버 로그 보기](그 파일을 하단 [서버 로그] 로 띄웁니다) · [아라에게 물어보기] 가 나옵니다.

서버 작업대 (탐색기 창)

Ctrl+Shift+O 를 누르면 폭이 넓은 작업대 창이 뜹니다. 왼쪽 트리보다 할 수 있는 일이 많습니다.

  • 탭 여러 개로 서버·폴더를 나란히 열기
  • 업로드 · 다운로드 · 서버 ↔ 서버 복사(끌어다 놓기)
  • 새 폴더 · 이름 바꾸기 · 복사 · 잘라내기 · 삭제(확인을 거칩니다)
  • 이름으로 거르기, 뒤로 · 앞으로

텍스트 파일은 더블클릭하면 열립니다. 고쳐서 저장하면 그대로 서버에 올라갑니다. 큰 파일이나 바이너리는 열지 않고 안내합니다.

💡 전송은 진행률이 보이고, 끊긴 전송은 이어받기를 시도합니다. 창을 닫아도 전송은 계속됩니다.

6. 서버를 마우스로

SSH 세션에서 상태 표시줄 오른쪽 끝의 아이콘이나 오른쪽 아이콘 바 맨 아래 토글을 누르면 화면 아래에 표가 펼쳐집니다. 도구는 열 개이고 탭으로 섭니다. 표 오른쪽 위에 어느 서버 것인지가 항상 찍혀 있습니다. 세션 탭을 다른 서버로 바꾸면 표도 그 서버 것으로 따라옵니다.

하단 패널의 도구 열 개 (탭에 서는 순서)
포트 모니터열린 포트와 프로세스. 원격 포트를 내 PC로 당겨오는 포워딩도 여기서. 행마다 [로그] 버튼이 있어 그 포트를 쓰는 프로그램의 출력을 바로 띄웁니다.
시스템 모니터CPU · 메모리 · GPU · 네트워크 실시간 그래프.
프로세스PID · 사용자 · CPU · 메모리 · 명령. 정렬 · 검색 · 종료(확인 후).
서비스systemd 유닛과 상태. 시작 · 정지 · 재시작. systemd 가 없으면 안내가 나옵니다.
디스크파일시스템 사용량 → 폴더로 파고들기 → [뒤로]. 큰 폴더 찾기에 씁니다.
패키지설치된 패키지 목록(배포판별 도구를 알아서 고릅니다).
컨테이너도커 · 포드먼 컨테이너 목록. 정지 · 일시정지 · 제거 · 컨테이너 접속까지 마우스로.
쿠버네티스이 노드의 파드(containerd). 파드로 묶어 준비 상태 · 재시작 · 나이 · CPU · 메모리를 보여 주고 아픈 파드를 위로 올립니다. 모니터링 전용 — 조작은 없습니다.
세션 기록지금 세션에서 실행한 명령과 그 결과.
서버 로그백그라운드로 도는 서버의 출력을 실시간으로 봅니다. 포트 번호(예: 8000)나 로그 파일 경로를 넣으면 됩니다.

서버 로그 — 볼 수 있을 때와 없을 때

포트 번호를 넣으면 그 포트를 쓰는 프로그램의 출력이 어디로 가는지 찾아 띄웁니다. 찾지 못하는 경우가 있고, 그때는 왜 못 보는지를 그대로 말합니다.

  • 출력을 버리는 프로그램(> /dev/null 로 띄운 것)은 볼 것이 없습니다. 다시 띄울 때 > ~/app.log 2>&1 를 붙이면 그때부터 볼 수 있습니다.
  • 다른 사용자나 root 가 띄운 것은 권한이 없어 못 봅니다. 이때는 [관리자 권한으로 찾기] 를 제안합니다 — 들여다보기만 하고 아무것도 바꾸지 않습니다.
  • tmux 안에서 도는 것은 로그 파일이 없어, "그 화면에 나오는 것을 파일로도 써 달라"고 tmux 에 부탁해야 합니다. 동의를 받고 진행하며, 프로그램은 그대로 돌아갑니다.
🛑 바꾸는 작업은 반드시 확인을 거칩니다. 종료할 프로세스나 다룰 서비스의 이름을 문구에 박아 보여 주고, 실패하면 서버가 준 이유(권한 부족 등)를 그대로 보여 줍니다. sudo 는 붙이지 않습니다.

7. 원격 데스크톱 (RDP)

윈도우 서버의 화면을 아라 탭 안에서 봅니다. 원격 데스크톱 연결(mstsc)이나 다른 프로그램을 따로 띄우지 않습니다. 터미널·파일·RDP 가 한 창에 있는 것이 이 기능의 값입니다.

7.1 붙기

  1. [연결] 탭 → ＋ → 맨 위에서 [RDP] 를 고릅니다(포트가 3389 로 바뀝니다).
  2. 이름 · 호스트 · 사용자를 넣고 저장합니다. RDP 는 비밀번호 하나뿐이라 SSH 처럼 인증 방식(비밀번호/공개키)을 고르는 칸이 없습니다. 비밀번호 칸은 선택입니다 — 채워 두면 다음부터 입력 화면 없이 바로 붙고, 비워 두면 접속할 때마다 묻습니다.
  3. 트리에서 더블클릭하면 탭이 열립니다. 비밀번호를 저장해 두지 않았다면 그때 묻습니다 (화면에 "이 서버의 비밀번호를 입력하세요. 저장하지 않습니다." — 그 자리에서 입력한 값만 안 남긴다는 뜻입니다).

탭 머리에 [인증 대기] → [연결 중…] → [연결됨] 이 차례로 표시됩니다. 실패하면 서버가 준 이유를 그대로 보여 줍니다(비밀번호 틀림 · 로그인 실패 · 권한 부족 · NLA/TLS 협상 거부 등)와 함께 [다시 시도] 가 나옵니다.

7.2 화면 크기 · 다중 모니터

화면 위 [옵션] 안에 전부 들어 있습니다(좁은 창에서 버튼이 줄바꿈되지 않도록 하나로 접어 두었습니다).

해상도기본은 [창 크기에 맞춤] — 창을 키우면 원격 화면도 따라 커집니다. 고정 해상도 다섯(1280×720 · 1366×768 · 1600×900 · 1920×1080 · 2560×1440)도 고를 수 있습니다.
다중 모니터모니터 전체를 덮는 창으로 새로 붙습니다.
  • 창 맞춤일 때 크기는 4의 배수로 맞춰 보냅니다 — 일부 서버가 어중간한 폭에서 화면을 깨뜨리기 때문입니다.
  • 접속 중에 크기를 바꾸는 것은 RDP 8.1 이상 서버에서만 반영됩니다. 그 아래 서버는 붙을 때의 크기로 고정됩니다.
  • 다중 모니터 창에서는 해상도를 고를 수 없습니다 — 모니터 배치가 크기를 정합니다.
  • 모니터가 한 장이면 [다중 모니터]는 아무 일도 하지 않고 그렇게 알려 줍니다. 모니터가 어긋나게 놓여 있으면 화면 일부가 어느 모니터에도 안 보인다고 알려 줍니다 — 디스플레이 설정에서 위아래를 맞추면 사라집니다.
⚠️ 다중 모니터 창에는 테두리가 없습니다 — OS 의 닫기 버튼도 없습니다. 나오는 길은 창 위쪽에 마우스를 올려 [닫기] 를 누르거나 Alt+Tab 입니다. 닫아도 탭의 화면은 그대로 남습니다.

7.3 클립보드 · 파일 주고받기

글자는 양방향으로 그냥 됩니다. 내 PC 에서 복사한 것을 원격에 붙여넣고, 반대도 됩니다. 이미지는 안 됩니다.

파일은 [옵션] 안에서 주고받습니다.

[파일 보내기]고른 파일을 원격 클립보드에 올립니다 — 원격 화면에서 Ctrl+V 로 붙여넣으세요. 화면에 끌어다 놓아도 같습니다.
[파일 받기]원격에서 Ctrl+C 로 복사한 뒤에 켜집니다. 누르면 저장 위치를 묻고 내려받습니다.

[파일 받기]가 회색이면 아직 원격에서 복사하지 않은 것입니다 — 항목 오른쪽에 "원격에서 Ctrl+C" 라고 조건이 글자로 붙어 있습니다. 아직 붙기 전이라면 파일 항목 자체가 나오지 않습니다.

7.4 단축키 보내기 · Mac 키 배열

[옵션] → [단축키 보내기] 로 Ctrl+Alt+Del · Alt+Tab · Win 을 원격에 보냅니다.

💡 Alt+Tab 을 직접 누르면 내 PC 의 윈도우가 가로챕니다 — 내 쪽 창이 바뀔 뿐입니다. 원격에 보내려면 반드시 이 항목으로 보내세요.

Mac 에서는 [키 변환] 이 자동으로 켜져서 ⌘ 자리를 Alt 자리로, ⌥ 자리를 Win 자리로 바꿔 보냅니다. ⌘ 를 Ctrl 로 보내는 배열도 고를 수 있고, 끌 수도 있습니다.

7.5 안 되는 것

겪기 전에 알아 두시는 편이 낫습니다. 셋 다 우리 쪽 한계이고, 잘못 쓰셔서 그런 것이 아닙니다.

마우스 커서 모양이 안 바뀝니다 창 가장자리에 올려도 화살표 그대로입니다(크기 조절 자체는 됩니다 — 모양만 안 바뀝니다). 글자 입력 자리에서 I 모양으로도, 로딩 중에 뱅뱅이로도 바뀌지 않습니다.
왜: 우리가 쓰는 원격 데스크톱 엔진이 커서 모양 전달을 꺼 둔 채로 배포돼 있고, 앱 쪽에서 그 값을 켤 손잡이가 없습니다. 엔진을 다시 만들어야 고쳐집니다.
탭을 창 밖으로 못 뗍니다 터미널 탭은 되는데 RDP 탭만 안 됩니다.
왜: 원격 화면을 그 창이 직접 들고 그리고 있어서 다른 창으로 넘길 수가 없습니다. 터미널은 화면 뒤쪽에서 돌아가는 것이라 옮길 수 있는 것과 다릅니다.
앱을 껐다 켜면 안 돌아옵니다 터미널·SSH 탭은 복원되지만 RDP 탭은 복원되지 않습니다. 다시 켠 뒤 트리에서 다시 붙어 주세요(비밀번호를 저장해 두지 않았다면 그때 다시 묻습니다).
ℹ️ [옵션] 안이 이 기능의 전부입니다. 해상도 · 다중 모니터 · 클립보드 파일 · 단축키 보내기 · 키 변환은 다른 진입점이 없습니다 — 찾는 것이 있으면 먼저 [옵션]을 열어 보세요.

8. AI — 아라 대화 · AI CLI · [AI 세션] 목록

ℹ️ AI 는 세 갈래입니다. 아라 대화는 앱 안에서 아라와 이야기하는 것이고(8.1), AI CLI 시작은 서버에서 claude·codex·gemini 를 띄우는 것이며(8.2), [AI 세션] 목록은 그렇게 띄운 AI 들이 지금 무엇을 하는지 보는 곳입니다(8.3). 앞엣것은 우리 화면으로, 가운데것은 그 CLI 의 화면 그대로 씁니다.

8.1 아라 대화 — 우측 [아라]

오른쪽 아이콘 바의 [아라] 를 누르면 대화가 열립니다(Alt+A). 이 PC 에 깔린 Claude Code 를 그대로 씁니다 — 내 계정, 내 설정, CLAUDE.md·스킬·플러그인이 전부 그대로 걸립니다. 별도 요금이 붙지 않습니다.

  • 서버를 압니다. "지금 붙어 있는 서버 알려 줘" 같은 말이 통합니다 — 아라의 도구(세션 목록·터미널 출력 읽기·파일 전송·포트 포워딩)를 대화 안에서 씁니다. 그 도구를 쓸 때는 승인 창이 뜹니다.
  • 한 일을 숨기지 않습니다. 도구를 쓰면 "도구 2개 썼습니다" 한 줄로 접혀 있고, 누르면 무엇을 어떤 인자로 했는지 펴집니다.
  • 갈림길에서 물어봅니다. 선택지가 알약 버튼으로 뜨고 1·2·3 숫자 키로도 고릅니다.
  • [계획 먼저] 를 켜면 아무것도 건드리지 않고 계획만 세웁니다. 계획을 보고 [이대로 진행] 을 누르면 그때 실행합니다 — 기다림 없이 바로 이어집니다.
  • 모델을 도중에 바꿔도 대화가 이어집니다(다시 시작하지 않습니다).
  • 비용·턴과 [중지] 가 입력칸 아래에 늘 있습니다.

[지난 대화] 에 대화가 기록으로 남습니다. 골라서 [이어서 열기] 하면 그 문맥 그대로 이어 갑니다(화면은 새로 채웁니다). 이름을 붙여 두면 나중에 찾기 쉽습니다.

작업 폴더는 묻지 않습니다. 보고 있는 로컬 셸의 폴더를 따라가고, 없으면 아라 폴더에서 시작합니다. 머리에 늘 보이고 눌러서 옮깁니다. 서버 일은 폴더가 아니라 위 도구로 합니다.

이 PC 에 claude 가 없으면 설치 명령과 함께 [API 키로 쓰기] 를 안내합니다. 그쪽은 도구 없이 대화만 되고 API 키(별도 결제) 를 씁니다 — 켜져 있으면 머리에 API 키 배지가 붙습니다. 머리의 스위치로 언제든 되돌아옵니다.

8.2 AI CLI 시작 — 서버에서 띄우기

한 번에 시작하기

Ctrl+Shift+L 을 누르면 새 탭이 열리면서 그 자리에서 CLI 가 바로 뜹니다. 무엇을 고르는 창이 없습니다 — 지금 보고 있는 세션의 서버와 폴더를 그대로 쓰고, CLI 와 플래그는 그 조합으로 마지막에 쓴 값(없으면 설정 [AI] 의 기본 플래그)을 씁니다.

  • 탭바 ＋ 옆 화살표, 파일 트리의 폴더 우클릭, 서버 트리 우클릭에서도 시작합니다.
  • 사이드바가 [AI 세션] 탭으로 저절로 넘어갑니다(터미널 탭을 열 때는 안 넘어갑니다). 접혀 있는 사이드바를 펴지는 않고, 방금 손으로 다른 탭을 고르셨으면 그 선택을 존중합니다.
ℹ️ 그 탭의 프로세스가 곧 CLI 입니다. 셸에 명령을 타이핑해 넣는 것이 아니라, 탭 자체가 CLI 로 뜹니다. 그래서 위에 옛 명령 출력이 남지 않고, 반대로 CLI 를 끝내면 세션도 끝납니다([프로세스 종료] 카드가 남아 결과를 볼 수 있습니다).
⚠️ 갓 띄운 셸에서는 안 뜹니다. 아직 그 세션이 어느 폴더에 있는지 모르기 때문입니다 — "이 세션이 어느 폴더에 있는지 아직 몰라 AI 를 띄울 수 없습니다" 라고 나옵니다. 아무 명령이나 한 번 실행해 폴더를 알려 주면 됩니다.
그리고 서버에 그 CLI 가 깔려 있는지는 미리 확인하지 않습니다. 없는 서버에서는 탭이 열린 뒤 command not found 가 그대로 보입니다.

터미널에 직접 쳐서 띄운 claude 도 그대로 [AI 세션] 목록에 올라옵니다 — 이 단축키는 길을 하나 더한 것이지 대체한 것이 아닙니다.

기본 플래그

설정(Ctrl+,) → [AI] 에서 CLI 마다 붙일 기본 플래그를 정합니다. claude 는 권한 확인 건너뛰기와 이전 대화 이어서가 기본으로 켜져 있고, codex·gemini 는 전부 꺼져 있습니다 — 승인 절차를 건너뛰는 플래그를 앱이 먼저 켜 두지 않습니다.

원격 로그인은 클릭 한 번

헤드리스 서버에서 claude·gemini 에 로그인하면 인증 링크가 서버의 localhost 로 돌아옵니다. 그 링크를 Ctrl+클릭하면 아라가 콜백 포트를 그 번호 그대로 터널링하고 내장 브라우저로 엽니다. 무엇이 열리는지 먼저 보여 주고 동의를 받습니다.

  • git 저장소가 아니면 안 됩니다.
  • 원격이면 그 서버에 먼저 접속해 있어야 합니다.
  • 목록에서 지워도 폴더와 브랜치는 그대로 남습니다 — 정리는 손으로 하세요.

9. 링크 · 포트 · 브라우저

터미널에 찍힌 주소는 Ctrl+클릭으로만 열립니다(그냥 클릭으로는 열리지 않습니다).

Ctrl+클릭원격 세션의 주소면 아라 브라우저로 엽니다. localhost 주소는 터널을 자동으로 뚫어 내 PC에서 볼 수 있게 합니다.
Ctrl+Alt+클릭내 PC의 기본 브라우저(크롬 등)로 보냅니다. 즐겨찾기나 로그인 세션이 있는 쪽에서 열고 싶을 때.

원격 CLI 로그인처럼 콜백 포트가 필요한 주소는 어떤 포트를 여는지 먼저 보여 주고 확인을 받은 뒤에 터널을 만듭니다. 아라 브라우저는 앱과 분리된 저장 공간에서 돌고 파일 다운로드와 새 창 띄우기를 막아 둡니다.

10. 세션 기록

세션마다 주고받은 내용이 파일로 남습니다. 비밀번호·토큰으로 보이는 값은 가려서 기록하고, vim·htop 같은 전체 화면 프로그램의 화면 갱신은 남기지 않습니다.

  • 하단 [세션 기록] — 지금 세션의 명령과 결과
  • 오른쪽 [지난 세션] — 지난 세션 목록. 진행 중인 것을 누르면 하단으로 보냅니다
  • 보존 기간(7 · 30 · 90일 · 무제한)과 기록이 쌓이는 폴더는 설정 → [로그]에서 정합니다

13. 업데이트

아라는 실행 중에 사내 배포 서버를 조용히 확인합니다(하루에 몇 번). 새 버전이 있으면 알려만 드립니다 — 내려받기는 [받기]를 누르실 때 시작합니다. 받은 뒤에는 앱을 다시 켤 때 적용되고, 지금 바로 적용하려면 [다시 시작하여 설치] 를 누르면 됩니다.

🔒 왜 한 번 더 눌러야 하나. 지금 배포 경로는 사내망 안의 평문 http 이고, 빌드에 아직 코드 서명이 없습니다. 이 조합에서 자동으로 받아 두면 "누가 올린 것이든 받아서 설치 대기까지 걸어 두는" 길이 열립니다. 그래서 받는 순간만큼은 사람이 정하도록 해 두었습니다 — 확인은 앱이, 결정은 사람이. 코드 서명은 다음 판의 과제입니다.

어디에서 알려 주나

  • 켤 때 한 번 — 새 버전이 나오면 창이 하나 뜹니다. [나중에] 를 누르면 그 버전으로는 다시 묻지 않습니다(다음 버전이 나오면 그때 다시 묻습니다).
  • 화면 맨 아래 오른쪽 — 평소 버전이 적혀 있는 자리가 [↑ 1.0.0 있음] 으로 바뀝니다. 눌러서 바로 받을 수 있고, 창을 [나중에]로 닫아도 이 자리는 남습니다. 받는 중에는 [↓ 42%], 다 받으면 [✓ 1.0.0 준비됨].
  • 설정 → [일반] → 업데이트 — 언제든 여기서 지금 상태를 보고 [업데이트 확인] 으로 즉시 확인할 수 있습니다.
⚠️ [✓ 준비됨] 을 눌러 설치하면 앱이 껐다 켜집니다 — 열려 있는 터미널과 SSH 연결이 모두 끊깁니다. 그래서 이때만 한 번 더 확인을 받습니다. 그냥 두셔도 됩니다. 다음에 앱을 껐다 켤 때 저절로 적용됩니다.

14. 문제 해결

접속이 안 됩니다

  • 실패하면 서버가 준 응답을 그대로 보여 줍니다. 그 문구를 먼저 보세요.
  • 비밀번호가 바뀐 서버는 [비밀번호 다시 입력]으로 갱신합니다.
  • 호스트 키 경고가 뜨면 접속을 강행하지 말고 관리자에게 확인하세요.

한글이 깨집니다

아라는 한글 고정폭 폰트를 함께 담고 있어 서버에 폰트가 없어도 깨지지 않습니다. 그래도 어긋나면 설정 → [폰트]에서 다른 후보를 골라 같은 문장으로 비교해 보세요. 서버 쪽 로캘(LANG)이 UTF-8 인지도 확인하세요 — 로캘 문제는 폰트로 해결되지 않습니다.

프롬프트의 아이콘이 네모(□)로 나옵니다

oh-my-zsh · starship 처럼 아이콘 글자를 쓰는 프롬프트 때문입니다. 아라에는 Symbols Nerd Font Mono 가 함께 들어 있어 대개 그대로 보입니다. 안 보이면 설정 → [폰트]에서 터미널 글꼴을 바꿔 보세요.

화면 글자가 작습니다

설정 → [일반] → UI 글자 크기. 터미널 글자 크기는 [폰트]에서 따로 정합니다.

파일 트리가 안 따라옵니다

AI 상태가 전부 [확인 불가] 입니다

그 서버에 상태 훅이 심기지 않은 것입니다. 설정 → [AI] → [원격 상태 훅] 에 서버별로 왜 그런지가 한 줄씩 나옵니다 — 자세한 것은 §4.4. AI 실행 자체는 훅과 무관하게 그대로 됩니다.

원격 데스크톱에서 커서 모양이 안 바뀝니다

알려진 한계입니다. 잘못 쓰신 것이 아닙니다 — §7.5 를 보세요.
