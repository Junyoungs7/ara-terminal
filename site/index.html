아래 왼쪽은 SSH 클라이언트로 서버를 다룰 때 보통 하는 일입니다. 오른쪽이 아라에서 같은 일을 하는 방법입니다.

보통의 SSH 클라이언트 A.R.A
서버가 왜 느린지 볼 때 top · ps -eo · systemctl · df 를 외워서 타이핑, 결과는 글자 더미 표로 봅니다. 프로세스·서비스·디스크·패키지·컨테이너·포트·시스템 그래프를 클릭으로 열고 정렬·검색·종료까지 마우스로. 서버에는 아무것도 설치하지 않습니다.
파일을 옮길 때 창을 하나 더 띄우거나 scp 명령을 조립. 터미널에서 cd 한 곳과 파일 창이 따로 논다 왼쪽 트리가 cd 를 따라옵니다. 끌어다 놓으면 업로드, 서버 ↔ 서버도 바로 복사. 원격 파일은 더블클릭해 고치고 저장하면 그대로 올라갑니다.
원격 CLI 로그인(claude·gemini) 콜백 포트를 손으로 포워딩하고, 링크를 복사해 브라우저에 옮겨 붙인다 링크를 Ctrl+클릭. 콜백 포트를 그 번호 그대로 터널링하고 내장 브라우저로 엽니다. 로그인이 그 자리에서 끝납니다.
서버가 띄운 웹을 볼 때 -L 3000:localhost:3000 을 기억해 다시 접속 터미널에 찍힌 localhost:3000 을 Ctrl+클릭하면 터널이 생기고 창이 열립니다.
창을 늘려 쓸 때 탭은 그 창에 갇혀 있다. 모니터를 옮기려면 새로 접속 크롬처럼 탭을 끌어내면 새 창, 끌어다 놓으면 합쳐집니다. 세션은 끊기지 않습니다.
다시 켰을 때 처음부터 접속하고 폴더로 다시 이동 세션 · 분할 배치 · 작업 폴더까지 복원됩니다.
기록이 필요할 때 직접 켜고, 파일을 직접 관리 자동으로 남습니다. 비밀값은 가려서, 보관 기간과 폴더는 설정에서.
한글 영문 화면. 서버에 폰트가 없으면 표·박스가 어긋난다 화면·메뉴·안내가 한국어. 한글 고정폭 폰트를 담아 배포해 서버 사정과 무관하게 정렬이 맞습니다.
새 버전 공지를 찾아 설치본을 내려받아 다시 설치 사내 서버에서 알아서 받아 두고 다음에 켤 때 적용합니다.

서버에 에이전트를
설치하지 않습니다.

서버 관리 웹 도구는 보통 서버에 무언가를 깔아야 합니다. 운영 서버에 그 승인을 받는 일이 더 오래 걸립니다.

아라는 이미 열려 있는 SSH 연결로 표준 명령을 대신 실행하고 결과를 표로 그립니다. 서버에 남는 것이 없고, 접속할 수 있는 서버면 어디든 됩니다. 배포판이 달라도 같은 화면으로 보이도록 명령을 골라 씁니다.

  • 프로세스 · 서비스 · 디스크 · 패키지 · 컨테이너 · 포트 · 시스템 그래프 · 세션 기록
  • 바꾸는 작업(종료 · 서비스 정지)은 대상 이름을 보여 주고 확인을 받습니다
  • 실패하면 서버가 준 이유를 그대로 보여 줍니다(권한 부족을 숨기지 않습니다)

기본기도
밀리지 않습니다.

분할 · 탭 · 창

가로·세로 분할, Alt+방향키로 칸 이동, 칸 최대화. 탭을 끌어내면 새 창, 끌어다 놓으면 합쳐집니다.

tmux 를 마우스로

SSH 세션 우클릭에서 실행 중인 tmux 세션을 골라 붙습니다. 없는 서버면 항목이 잠기고 설치 안내가 나옵니다.

통합 검색 · 명령어 북

F1 하나로 기능·서버·명령을 한 곳에서 찾습니다. 자주 쓰는 명령 80여 개는 골라 담아 두었습니다.

호스트 키를 기억합니다

처음 붙는 서버는 지문을 보여 주고 확인을 받습니다. 다음에 지문이 달라지면 접속을 멈춥니다.

비밀은 파일에 안 둡니다

비밀번호 · 개인키 암구호 · API 키는 Windows 자격 증명에. 설정 파일에는 없습니다.

글자 크기와 폰트

앱 화면 배율과 터미널 글꼴을 따로 정합니다. 한글 폰트 후보를 같은 문장으로 비교해 고릅니다.
