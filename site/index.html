A.R.A(아라)는 SSH 터미널에 파일 탐색기 · 서버 도구 · AI 대화를 한 창에 담은 사내 개발자용 터미널입니다. 원격 리눅스에는 아무것도 설치하지 않습니다.

세션을 나누고, 떼어내고, 되돌립니다.

한 창을 가로·세로로 쪼개 여러 서버를 나란히 봅니다. 탭을 창 밖으로 끌면 크롬처럼 새 창이 되고, 다시 끌어다 놓으면 원래 창으로 돌아옵니다.

  • 가로/세로 분할 · 칸 최대화 · Alt+방향키로 칸 이동
  • 탭을 바깥으로 끌면 새 창 — 창끼리 탭을 주고받습니다
  • 앱을 껐다 켜면 세션 · 분할 배치 · 작업 폴더가 그대로 복원됩니다

파일은 끌어다 놓으면 갑니다.

왼쪽 트리에 원격 폴더가 그대로 펼쳐집니다. 탐색기에서 파일을 끌어다 놓으면 업로드하고, 서버와 서버 사이도 바로 복사합니다. scp 명령을 쓸 일이 없습니다.

  • 업로드 · 다운로드 · 서버 ↔ 서버 복사, 진행률과 이어받기
  • 터미널에서 cd 하면 트리도 따라 움직입니다
  • 원격 파일을 더블클릭하면 열어 보고 고쳐서 바로 저장합니다

AI는 옆자리에 앉아 있습니다.
손은 제 것이 아닙니다.

화면에 있는 출력·로그를 그대로 붙여 물어봅니다. 답에 담긴 명령은 터미널에 넣어 주기만 합니다 — 실행은 사람이 누릅니다. 첨부하는 내용에서 비밀번호처럼 보이는 값은 보내기 전에 가려집니다.

  • 사내 vLLM(호환 엔드포인트)과 상용 API 모두 사용 가능
  • API 키는 Windows 자격 증명에 저장 — 설정 파일에 남지 않습니다
  • 원격 claude · codex · gemini CLI 를 한 번에 시작

서버를 마우스로

원격 리눅스에
설치할 것은 없습니다.

데스크톱 환경도, 에이전트도 필요 없습니다. A.R.A가 이미 열려 있는 SSH 연결로 표준 명령을 대신 실행하고 결과를 표로 보여 줍니다. 정렬 · 검색 · 종료가 전부 마우스입니다.

프로세스

PID · 사용자 · CPU · 메모리 · 명령. 정렬하고 걸러서 찾고, 확인을 거쳐 종료합니다.

서비스

systemd 유닛 상태와 부팅 시 활성 여부. 시작·정지·재시작은 이름을 확인한 뒤에 나갑니다.

디스크

파일시스템 사용량에서 시작해 큰 폴더로 파고듭니다. 찾은 폴더는 탐색기로 바로 엽니다.

패키지 · 컨테이너

설치된 패키지와 도커 컨테이너 목록. 배포판이 달라도 같은 화면으로 봅니다.

포트 모니터

열린 포트와 그 주인을 봅니다. 원격 포트는 클릭 한 번으로 내 PC로 당겨 옵니다.

시스템 모니터

CPU · 메모리 · GPU · 네트워크를 실시간 그래프로. 보이지 않는 탭은 조회를 멈춥니다.

기본으로 안전하게

회사 자산이
조용히 새어 나가지 않게.

호스트 키를 기억합니다

처음 붙는 서버는 지문을 보여 주고 확인을 받습니다. 다음부터 지문이 달라지면 접속을 멈춥니다.

비밀은 파일에 안 둡니다

비밀번호 · 개인키 암구호 · API 키는 Windows 자격 증명에 들어갑니다. 설정 파일에는 없습니다.

보낼 내용을 먼저 가립니다

AI에 첨부하는 텍스트에서 토큰 · 비밀번호로 보이는 값을 가리고, 무엇을 보냈는지 보여 줍니다.

로그인은 아라 브라우저에서

원격 CLI의 OAuth 링크를 터널로 이어 내장 브라우저에서 마칩니다. 앱 데이터와 분리된 공간입니다.

지나간 것도 남습니다

세션마다 입력과 출력을 파일로 남깁니다. 보관 기간과 폴더는 설정에서 정합니다.

한국어가 먼저입니다

화면 · 메뉴 · 안내가 한국어입니다. 한글 폰트를 함께 담아 서버 글꼴이 없어도 깨지지 않습니다.

  1. 설치 파일을 실행합니다. 설치 경로를 고를 수 있습니다. 기본값 그대로 두어도 됩니다.
  2. 바탕화면의 거미 아이콘으로 실행합니다. 첫 화면에서 ＋ 를 눌러 로컬 셸이나 서버를 추가합니다.
  3. 업데이트는 알아서 받습니다. 새 버전이 준비되면 알려 드리고, 다시 켤 때 적용됩니다.
⚠️ SmartScreen 경고가 뜰 수 있습니다. 아직 코드 서명 전이라 "알 수 없는 게시자"로 나옵니다. [추가 정보] → [실행]으로 진행하세요.
🛡️ 보안 프로그램이 설치를 막으면 다시 시도하지 마세요. 그 화면을 그대로 알려 주시면 담당자가 예외 처리를 요청합니다.

자동 업데이트

실행 중에 사내 서버를 조용히 확인합니다. 새 버전이 있으면 뒤에서 받아 두고, 다음에 앱을 껐다 켤 때 적용합니다. 지금 바로 적용하려면 설정 → 일반 → 업데이트에서 [다시 시작]을 누르세요.

설치가 막힌다면

설치 파일이 지워지거나 실행이 차단되면 사내 보안 정책 때문일 수 있습니다. 재시도 대신 화면을 캡처해 담당자에게 알려 주세요.
