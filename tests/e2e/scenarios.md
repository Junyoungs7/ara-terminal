## 21. 파일 Ctrl+V → SFTP 업로드 (W1 F14, 2026-08-09 다중 선택 해소)

**받는 경로가 바뀌었다.** 전에는 Ctrl+V 키다운을 가로채 Electron clipboard API 로 경로를 읽었는데,
Windows 에서 그 API 는 **파일 하나만** 준다(CF_HDROP 은 번호 형식이라 이름으로 못 집고, 경로 한 개짜리
`FileNameW` 로 대신 읽었다). 가로채는 순간 브라우저 paste 이벤트까지 함께 막혀 정작 전부 알고 있는 쪽을
못 쓰고 있었다 — 그게 A-3(첫 파일만 올라감)의 진짜 원인이다. 실측 결과:

| 읽는 방법 | 파일 2개를 복사했을 때 |
|---|---|
| `clipboard.readBuffer('FileNameW')` | 1개 |
| `availableFormats()` 의 `text/uri-list` | 형식만 광고하고 읽으면 **빈 값** |
| PowerShell `Get-Clipboard -Format FileDropList` | 2개 (367ms + 프로세스 기동) |
| **브라우저 paste 이벤트** | **2개 + 실경로(Electron `File.path`)** ← 채택 |

편집 불가 요소(파일 트리)에서는 이벤트가 요소가 아니라 **document 로만** 온다(실측) — 그래서 document
캡처 리스너 하나로 받고 대상은 포커스로 고른다(`src/renderer/store/pasteFiles.ts`). RDP 화면의 64MB 상한도
이때 없앴다(진짜 `File` 핸들이라 디스크에서 조각내 읽는다 — main 이 바이트를 통째로 들고 있던 IPC 제거).

자동화 주의: **합성 KeyboardEvent 로는 재현되지 않는다.** `paste.spec.ts` 는 paste 이벤트를 직접 만들어
document 에 넣고(파일), 텍스트는 실제 클립보드 + Playwright 의 신뢰된 Ctrl+V 로 쏜다.

> 프로세스·같은 오리진**이라(file:// 포함, 실측) 부모가 자식 캔버스에 `drawImage` 로 직접 그릴 수

## 36. 서버 콘솔 (F26 R1+R2+R3 · F28 컨테이너)

렌더러가 원격에 넘길 수 있는 것은 **`{ cmdId, args }` 뿐이다 — 명령 문자열은 main 이 소유한다**

문자열을 실행시킬 길이 없다 — F23 이 MCP `session_create` 의 `shell` 자유 문자열을 보안 결함(S1)으로
들어낸 것과 같은 선을, 서버 콘솔은 처음부터 이 경계로 막았다.

쓰기 명령(`ps.kill`·`svc.action`)은 전부 확인 다이얼로그를 거친다 — **취소하면 원격에 명령이 한 번도
나가지 않는다**(CON-6·CON-12). 판정은 다이얼로그가 떴는지가 아니라 **하네스가 실제로 받은 명령 수**로
한다. 활성 세션이 바뀌면 표와 선택을 즉시 버린다(CON-8c·CON-14b) — 다른 서버의 PID·유닛을 죽이는
사고를 원천 차단한다. 숨은 도구 탭은 마운트를 유지하되 원격에는 명령을 보내지 않는다(폴링 정지).

systemd 가 없는 서버(CON-14)·로컬 세션(CON-10)은 **빈 표가 아니라 안내**를 낸다.

## 37. AI CLI 한 번에 시작 (F27, 신설)

서버 접속 → 폴더 이동/생성 → `claude --dangerously-skip-permissions -r` 세 단계를 진입점 하나로
끝낸다. 완료 보고 `agent_talk/F27-done.md`(설계 배경 `agent_talk/F27-task.md` §0), 캡처
`agent_talk/F27-screenshot.png`.

진입점은 **네 곳**이다 — 탭바 ＋ 드롭다운(AICLI-1) · 단축키 `Ctrl+Shift+L`(AICLI-2) · 원격 폴더
우클릭(AICLI-4) · 서버 트리 우클릭(AICLI-3).

**"보낼 명령" 줄은 실제 전송 문자열과 글자 하나 다르지 않다**(AICLI-5★ — ssh2 하네스가 shell 채널로
받은 바이트와 대조한다). 그 줄이 `cd ~/'projects/신규 작업' && claude --dangerously-skip-permissions -r`
꼴인 이유가 있다 — **물결표(`~`)는 따옴표 밖에 있다.** 작은따옴표 안에 넣으면(`cd '~/x'`) 셸이 홈으로
펼치지 않아 "그런 폴더 없음"이 된다(목업 초안 `agent_talk/F27-task.md` §1 은 이 형태를 틀리게 적어
뒀었다 — 그대로 갔으면 기본 경로에서 매번 실패했을 것이다).

CLI 가 없는 서버면 **안내가 뜨고 원격에는 아무것도 나가지 않는다**(AICLI-7★ — 판정은 화면이 아니라
하네스가 받은 입력 바이트 수, 0이어야 한다).

최근 목록은 **[시작]이 성공한 뒤에만 저절로 쌓인다** — 창에 저장 버튼이 없다. "저장이 전제가 되면
안 된다"는, 한 번 반려된 설계(작업 프로필에 실행 명령을 얹는 안)의 결론이다(`F27-task.md` §0): 처음
쓰는 사람도 아무것도 저장해 두지 않은 채로 바로 시작할 수 있어야 한다. 최근 항목을 눌러도 바로

뿐이라 **`styles/` 가 통째로 빠져 있었다.** 그 사이 `shell.css`·`interactions.css` 에 `font-size`
리터럴이 **229곳, 12종**(9 / 9.5 / 10 / 10.5 / 11 / 12 / 12.5 / 13 / 13.5 / 14 / 14.5 / 15.5px)으로
흩어져 한 번에 조절할 방법이 없었다. 척도 7단계(`--fs-micro`~`--fs-xl`)를 `tokens.css` 로 모으고,
**스캐너를 넓혀 다시 흩어지는 것을 막았다**(styles/ 의 font-size px 리터럴은 이제 게이트 실패).

- 본문 기준 **13.5px → 15px**. 하한을 세웠다 — **어떤 UI 글자도 11px 미만이 되지 않는다**
  (옛 9·9.5·10px 이 30곳 있었고 그게 "가독성이 떨어진다"의 실체였다).
- **행 높이도 같은 배율을 탄다**(`--row-titlebar`·`--row-statusbar`·`--row-tabbar`) — 글자만 키우면
  그 줄에서 잘린다. 글자를 담는 고정 높이 10곳은 `min-height` 로 바꿔 내용이 높이를 정하게 했다.
- **설정 [일반] → UI 글자 크기**(작게 / 보통 / 크게 / 아주 크게). 저장값은 숫자가 아니라 **이름**이라
  나중에 배율 수치를 다시 손봐도 고른 값이 산다. 터미널 글자는 이 배율을 타지 않는다(F5 자체 슬라이더).
- `transform: scale()` 은 쓰지 않는다 — 글자가 흐려진다.

**새 폴러를 만들지 않았다.** CPU·메모리·GPU 는 상태바 게이지가 이미 쓰는 `telemetry:data` 를 그대로

  **로컬 셸을 하나도 안 열어 둔 상태(SSH 만 쓰는 중)에서도** 보여야 해서 세션에 맬 수 없다.

  **CPU 와 같은 2.5초로 폴링하지 않는다**(30초): `df` 는 무겁고 디스크는 초 단위로 변하지 않는다.

그래프는 **차트 라이브러리 없이** 인라인 SVG `polyline` 이다. 표본 60개(2.5분) 링버퍼이고 **영속화하지
않는다** — 패널을 닫으면 버린다(오래된 값으로 "지금"을 그리지 않는다). 세션을 바꿔도 버린다: 이전
서버의 곡선을 새 서버 그래프에 이어 붙이면 거짓말이 된다.

**GPU 는 값이 올 때만 칸이 생긴다**(상태바 `gaugesOf()` 와 같은 규칙 — 없는 칸을 "—"로 남겨 두면
고장난 것처럼 보인다). 원격은 `nvidia-smi` 가 있으면 나오고, **내 PC 는 표시하지 않는다**:
Windows 에 무의존 조회 방법이 없고, 원격처럼 외부 명령을 내 PC 에서 주기적으로 실행하지는 않는다는
기존 판단(`LocalTelemetry.ts` 머리주석)을 유지했다. 그 자리에는 이유를 한 줄로 밝힌다.

사용률 톤(90% 빨강 / 75% 주황)은 **F26 디스크 창과 같은 경계**를 쓴다 — 같은 숫자가 화면마다 다른

## 40. AI 세션 패널 (F30, 2026-08-12 신설)

준영님: **"서버 3대에 Claude Code 를 띄워 두면 어느 놈이 승인을 기다리며 멈춰 있는지 모른다."**

**판정 근거는 "출력이 멎었다" 하나뿐이다.** 그래서 화면은 **관측한 사실만** 말한다 — "조용함 2분".
승인 대기일 수도, 60초 넘게 걸리는 빌드일 수도 있고 둘을 가를 방법이 마땅치 않다(원격 프로세스
상태를 봐도 대기와 수면이 안 갈린다). 추측("승인을 기다리는 중일 수 있습니다")은 알림 부제로 한 번만
덧붙이고, 패널 아래에 판정 근거를 밝힌다. **확신하는 척했다가 한 번 틀리면 그다음부터 아무도 이
표시를 안 믿고, 그러면 기능이 죽는다.**

기준 60초: 빌드·테스트가 30~60초 조용한 건 흔하고 진짜 승인 대기는 분 단위다. 써 보고 조정할 값이다.

정확히 그 안 보이는 탭들**이라 renderer 가 셀 수 없다. `session:list` 에 얹지 않은 이유는 그쪽이
workspace.json 으로 영속되는 타입이기 때문이다(매 출력마다 바뀌는 값을 넣으면 스냅샷이 늘 더럽다).

**패널을 닫아 두면 아무것도 안 보이는 것이 D안의 급소**였다 → 액티비티 바 아이콘에 점을 찍고,
OS 알림은 **앱이 뒤에 있을 때만**·세션당 한 번만 띄운다(앞에 있으면 점으로 충분하고, 알림이 겹치기
