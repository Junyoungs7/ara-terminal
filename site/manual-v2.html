ARA 2.x 사용 설명서

2.0 ~ 2.2.x 에서 되는 것만 정리했습니다. 서버 접속·파일 전송·원격 데스크톱 같은 터미널 쪽 기본기는 1.x 와 같아서 1.x 사용 설명서를 함께 보세요.

1. 설치와 1.x 에서 옮겨 오기

설치

  1. 다운로드에서 2.x 설치 파일을 받습니다.
  2. 실행해서 설치합니다. 아라가 켜져 있으면 "닫을까요?"를 묻고, 직접 닫은 뒤 이어서 설치합니다.
  3. 게시자는 Junyoung 으로 표시됩니다.
⚠️ "알 수 없는 게시자" 경고가 뜨면 [추가 정보] → [실행]으로 진행하세요. 아직 코드 서명 전입니다.

1.x 가 깔려 있다면

  • 설치하면서 1.x 를 자동으로 조용히 지웁니다. 따로 지울 필요가 없습니다.
  • 서버 목록과 설정은 그대로 남습니다(%APPDATA%\A.R.A).
  • 처음 켤 때 1.x 설정을 %APPDATA%\A.R.A\backup-1.x-날짜-시각 폴더에 복사해 둡니다.
  • 1.x 로 돌아가려면 1.0.33 을 다시 설치하고 그 폴더의 파일을 되돌립니다.

1.x 의 자동 업데이트로는 2.x 가 오지 않습니다. 위처럼 받아서 덮어 설치하세요. 2.x 끼리는 자동 업데이트됩니다.

🛡️ 보안 프로그램이 설치를 막으면 재시도하지 마세요. 화면을 캡처해 담당자에게 알려 주세요. (10. 자주 묻는 것)

2. 화면 둘러보기

2.x 는 화면이 두 공간입니다.

공간용도전환
터미널서버 연결, 로컬 셸, 분할, 탐색기 — 1.x 에서 하던 일Ctrl + Alt + 1
AI 작업에이전트(Claude Code·Codex·Gemini CLI)를 띄우고 변경을 검토Ctrl + Alt + 2
  • 타이틀바의 공간 전환에서도 고릅니다. 확인할 일이 있으면 표시가 붙습니다.
  • 왼쪽 위에는 ARA 로고, 메뉴는 ≡ 하나입니다. 하위 메뉴는 바깥 오른쪽에 뜹니다.
  • 타이틀바 가운데 통합 검색(F1)으로 기능·서버·숨긴 기능까지 찾습니다.
  • 상태바는 지금 탭의 계정@호스트·경로·OS·CPU·메모리·GPU·업타임을 보여 줍니다. 세션이 없으면 내 PC 입니다.
  • 아래 패널(포트·시스템 모니터 등)은 늘 닫힌 채 시작합니다. 서버 도구 아이콘이나 Ctrl + Shift + J 로 엽니다.

글라스 화면

2.2.0 부터 새 로고와 유리(글라스) 화면이 기본입니다. 드롭다운·모달·따로 뜨는 창까지 같은 모양과 색입니다.

설정

설정은 가운데 넓은 창으로 열립니다(Ctrl + ,). 위쪽 설정 찾기에 이름을 치면 바로 갑니다. 설정 › 서버 도구 에서 잘 안 쓰는 기능을 숨길 수 있고, 쿠버네티스·서버 로그·서버 콘솔은 기본으로 숨겨져 있습니다.

3. 터미널

서버 접속, 파일 전송, 서버 도구의 사용법은 1.x 설명서와 같습니다. 여기서는 2.x 에서 달라진 자리만 적습니다.

서버 연결

  1. 사이드바 머리에서 연결을 고릅니다. Ctrl + Shift + M 은 연결 관리자입니다.
  2. 서버를 눌러 접속합니다. ＋ 를 우클릭하면 SSH 연결을 고를 수 있습니다.
  3. 접속을 끝낸 서버 앞 점은 초록으로 남지 않고 꺼집니다.

자세한 것은 1.x 설명서 §4.

분할

  • 세로 분할 Ctrl + Shift + \ · 가로 분할 Ctrl + Shift + -
  • 칸 사이 이동 Alt + 방향키 · 칸 최대화 Ctrl + ↑
  • 창을 나누면 지금 쓰지 않는 창이 조금 어두워집니다.

탐색기 · 포트

  • 탐색기는 별도 창으로 열립니다(Ctrl + Shift + O). ✕ 는 창을 숨기기만 합니다.
  • 포트 모니터는 Ctrl + Alt + P. 포트·링크의 [열기]는 Oriel 이 있으면 Oriel 로 열립니다(5).

테마 · 셸

설정 › 터미널 에서 합니다.

셸새 로컬 터미널이 띄울 셸. [자동 (기본 셸)] 또는 [직접 지정…]. 이미 열린 터미널은 그대로입니다.
셸 인자고른 셸에만 붙는 시작 인자. 예: -NoProfile
터미널 테마글자·배경 색. 기본은 [아라 기본](앱 색을 따름). Ghostty·Warp 설정을 읽어 색·글꼴·커서를 미리 볼 수 있습니다(그 프로그램의 파일은 고치지 않습니다).
인라인 이미지터미널 프로그램이 보낸 이미지(sixel·iTerm2·kitty)를 그 자리에 그립니다. 새 터미널부터 적용됩니다.

죽은 화면 프로그램이 입력 모드를 남겼을 때는 Ctrl + Shift + R(터미널 초기화)로 되돌립니다.

4. AI 작업 공간

Ctrl + Alt + 2 로 AI 작업 공간에 들어갑니다. Claude Code · Codex · Gemini CLI 를 한 곳에서 띄우고 지켜봅니다.

4.1 시작하기 n/8

사이드바의 시작하기 n/8 에서 기본 설정을 단계별로 마칩니다. 하면 저절로 체크되고, 다 하면 줄이 사라집니다(설정 › 시작하기).

  1. 기본 에이전트 고르기
  2. 알림 켜기
  3. 에이전트에 아라 스킬 주기
  4. GitLab 연동
  5. 작업 단위 준비 자동화
  6. 저장소 두 개 추가
  7. 작업 두 개 동시에
  8. Oriel 브라우저 쓰기

4.2 워크트리 = 작업 단위

일 하나에 폴더(워크트리) 하나를 만들어, 여러 에이전트가 서로 파일을 건드리지 않게 합니다.

  1. 사이드바 워크트리 머리에서 프로젝트 추가로 git 저장소(또는 폴더)를 넣습니다.
  2. 새 작업(+)을 눌러 만듭니다. 분기 지점을 고를 수 있고, 만드는 진행이 보입니다.
  3. git 저장소가 아니거나 무거운 저장소면 워크트리 없이 그 폴더에서 바로 돌릴 수도 있습니다.
  • 사이드바는 이름으로 찾기, 프로젝트별로 묶기, 고정을 지원합니다. 세션이 살아 있는 워크트리는 초록 점입니다.
  • 탭 묶음은 워크트리마다 따로입니다. 워크트리를 바꾸면 그 워크트리의 탭들이 나옵니다.
  • 워크트리 점프: Ctrl + Shift + J (AI 작업 공간에서).
  • 재우기·보관·정리 화면, 아라 밖에서 만든 워크트리 보기, 저장소 맨 위 orca.yaml 설정 파일(예: scripts.setup 에 적은 준비 명령을 새 작업 단위마다 실행)을 지원합니다.

4.3 에이전트 실행

  1. 워크트리를 고릅니다.
  2. Ctrl + Shift + L 로 에이전트 실행 피커를 엽니다. 설치된 에이전트가 보입니다.
  3. 첫 지시를 적고(비워 두면 그냥 띄움) Ctrl + Enter 로 실행합니다.
  • 바로 띄우기: Alt+1 Claude Code · Alt+2 Codex · Alt+3 Gemini CLI.
  • 설치된 에이전트가 안 보이면 [다시 찾기]. 기본 에이전트·새 탭 보기 방식은 설정 › 에이전트 에서 정합니다.
  • 일하는 중 · 끝남 · 답 기다림이 사이드바와 상태 칩에 보입니다. 훅 신호가 없으면 화면으로 판정한 추정으로 표시됩니다.
  • 서브에이전트는 자식 줄로 보입니다. 대시보드에서는 띄운 에이전트가 상태별로 모입니다.
ℹ️ 권한은 에이전트별 권한 설정을 따릅니다. 새 탭을 띄울 때 피커에서 그 탭만 바꿀 수 있습니다.

4.4 채팅 보기 ↔ 터미널

에이전트 탭은 같은 세션을 채팅으로도, 터미널로도 볼 수 있습니다.

  • 탭 줄의 [채팅]/[터미널] 이나 Ctrl + Shift + U 로 바꿉니다.
  • 설정 › 에이전트 › 새 탭 열기 에서 새 탭을 CLI(터미널)로 열지 채팅으로 열지 정합니다.
  • 채팅에 적어 보낸 글은 그 세션의 터미널에 입력됩니다. 파일은 끌어다 놓거나 붙여넣고(경로만 넘어갑니다), Enter 보내기 · Shift+Enter 줄바꿈.
  • 도구 호출은 문단 사이 한 줄로 보입니다(걸린 시간·바뀐 줄 수·시험 통과 수).
  • 열면 맨 아래에서 시작하고, 읽는 중에는 스크롤을 건드리지 않습니다(아래에 "새 내용" 단추).

4.5 질문 · 승인

에이전트가 묻거나 허락을 구하면 에이전트의 질문·승인 카드와 알림으로 옵니다.

  • 도구 실행 허락은 [허용] / [거부]. 질문은 고르거나 [직접 입력]하고 [보내기].
  • 채팅 보기에서는 승인을 터미널에서 답해야 하는 경우가 있습니다. 그때 채팅에 띠로 알려 줍니다.
  • 설정 › 알림 에서 에이전트 알림을 켜 두면 끝났거나 기다릴 때 바로 압니다.

4.6 지난 세션 · 이어 하기

왼쪽 레일의 지난 세션에 Claude Code·Codex·Gemini CLI 로 일한 기록이 최신순으로 보입니다.

  • [재개]로 이어 하거나 [재개 명령 복사]로 터미널에서 이어 갑니다. 첫 지시 복사도 됩니다.
  • 범위(이 작업 단위·프로젝트·전체), 정렬, 묶기, 에이전트별 거르기가 됩니다.
  • 검색 칸에 두 글자부터 치면 대화 전문 검색을 합니다.
  • [삭제]는 기록 파일을 휴지통으로 옮깁니다. 지우면 그 세션은 재개할 수 없습니다.

4.7 변경 비교 · 코드 보기 · 새 탭

  • 변경 비교: 오른쪽 아이콘 줄에서 엽니다. 작업 단위에서 바뀐 파일을 나란히(또는 한 줄로) 비교합니다. 그림·HTML 도 비교하고, 충돌은 충돌 검토로 파일만 모아 봅니다. 줄에 의견을 달 수 있습니다(Ctrl + Enter 로 저장).
  • 코드 보기: 에디터에서 고치고, 마크다운·Mermaid·CSV 는 미리 봅니다. 디스크가 밖에서 바뀌었으면 저장하지 않고 띠로 알립니다.
  • 소스 제어에서 커밋합니다(메시지 입력 후 Ctrl + Enter).
  • 새 탭(탭 줄의 [+])은 늘 보입니다. 열린 탭·파일·URL(Oriel)·에이전트를 한 칸에서 찾아 엽니다. 예: localhost:3000

4.8 잠재우기 · 펫

  • 쉬는 에이전트 재우기(설정 › 에이전트, 기본 꺼짐): 끝나고 안 보는 탭을 정한 시간(1~1440분, 기본 30분) 뒤 멈추고 탭에 z 를 남깁니다. 그 탭으로 돌아오면 같은 세션으로 이어 띄웁니다.
  • 펫(설정 › 펫, 기본 꺼짐): [펫 보이기]를 켜고 [펫 그림]에 내 그림을 올립니다. 화면 오른쪽 아래에서 에이전트 상태(일함·기다림·검토)에 따라 움직입니다. 끌어서 옮길 수 있습니다.
  • 컴퓨터 깨어있기(설정 › 에이전트): 에이전트가 일하는 동안 화면·PC 절전을 막습니다. [끔] · [에이전트가 일할 때만] · [항상].

4.9 사용량

상태바와 사용량 팝오버에 Claude·Codex CLI 로그인 기준 구독 사용량이 보입니다(누르면 자세히). Gemini 사용량은 설정 › 계정·사용량 에서 켭니다. 조회가 잠시 막히면 나중에 다시 확인합니다.

4.10 예약 실행

설정 › 자동화·예약 실행 에서 에이전트 작업을 시각에 맞춰 돌립니다.

⚠️ 아라가 켜져 있는 동안 아라 안에서만 돕니다. Windows 작업 스케줄러에는 등록하지 않습니다. 아라나 PC 가 꺼져 있어 놓친 시각은, 정한 유예 시간 안에 다시 켜면 한 번 실행합니다.

4.11 GitLab · Slack 연동

연동어디서 / 하는 일
GitLab설정 › 연동 › [사내 GitLab 연동]. 주소와 개인 액세스 토큰(api 권한)을 넣으면 소스 제어에서 MR 목록을 보고 [MR 만들기]로 올립니다. 꺼져 있으면 GitLab 에 아무 요청도 보내지 않고, 저장소 origin 이 그 주소일 때만 토큰을 보냅니다.
Slack설정 › Slack › [Slack 연결]. 사내 Slack 앱에 나가는 연결만(Socket Mode)으로 붙어, 정한 채널에 질문·승인 카드와 "끝났습니다" 알림을 올립니다. 명령은 정해 둔 사용자만, 그 채널과 봇 DM 에서만 받습니다. [시작·이어 지시 받기]는 따로 켜야 합니다.
🛡️ Slack 으로 보낸 지시와 카드·턴 결과(에이전트 출력 일부)는 Slack 에 남습니다. 비밀이 담긴 작업 결과는 Slack 으로 받지 마세요. 토큰은 PC 의 보안 저장소에 암호화해 저장합니다.

5. Oriel (따로 설치하는 AI 브라우저)

Oriel 은 아라와 따로 설치하는 브라우저입니다. 아라는 설치된 Oriel 을 자동으로 찾습니다. 없어도 아라는 그대로 쓸 수 있습니다.

링크 열기

  • 터미널·에이전트 탭의 링크는 Ctrl + 클릭으로 엽니다. 글자 뒤에 주소가 숨은 링크도 열립니다.
  • Oriel 이 켜져 있으면 거의 바로 Oriel 로, 없으면 기본 브라우저로 열립니다.
  • Oriel 로 열면 아라 테마를 따라갑니다(Oriel 0.1.1 이상).

에이전트가 브라우저 쓰기

  • Oriel 이 있으면 에이전트가 웹을 보고 조작하며 확인·테스트합니다. 아라가 에이전트를 띄울 때 그 실행에만 Oriel 을 붙입니다. 내 MCP 설정은 그대로입니다.
  • 설정 › 에이전트 › Oriel (웹 도구) 에 찾은 위치가 보입니다. 못 찾으면 그 칸에 설치 위치를 적습니다.
  • Oriel 이 없으면 에이전트는 웹 도구 없이 시작하고, 알림으로 알려 줍니다.

요청 보내기

Oriel 에서 고른 화면 조각이나 메모를 에이전트에게 요청으로 보낼 수 있습니다. 아라는 Oriel 에 어느 세션의 어느 AI 인지 이름을 넘겨 줍니다(Oriel 0.1.3 이상). 보내는 방법은 Oriel 쪽 안내를 보세요.

6. ara CLI

터미널이나 에이전트가 ara 명령으로 작업 단위와 터미널을 다룹니다.

  • 아라가 띄운 에이전트·터미널 탭에서는 설치 없이 ara 가 됩니다.
  • 그 밖의 터미널에서 쓰려면 설정 › 스킬 의 [CLI 설치]. 사용자 PATH 에 아라 설치 폴더의 bin 한 줄만 넣고, [제거]로 그 한 줄만 뺍니다. 새로 연 터미널부터 보입니다.
  • 같은 자리의 번들 스킬 ara-cli 를 [설치]하면 에이전트가 작업 단위 만들기·메모·넘기기·터미널 읽기를 하는 법을 압니다.
명령하는 일
ara status아라가 켜져 있는지
ara open아라를 켜고 창이 뜰 때까지 기다림
ara repo list프로젝트 목록
ara worktree list · current · show작업 단위 보기
ara worktree create --name 이름작업 단위 만들기(--agent claude|codex|gemini --prompt 지시 로 바로 실행)
ara worktree set메모·상태 바꾸기
ara worktree rm작업 단위 지우기
ara terminal list · create · send · read터미널 목록·만들기·글자 보내기·화면 읽기
ara agent launch에이전트 띄우기

대부분의 명령은 --json 으로 기계가 읽기 좋게 받을 수 있습니다.

7. 앱 잠금 · 보안

설정 › 잠금 에서 켭니다. 기본은 꺼짐입니다.

  • 켜면 저장된 서버 비밀번호·키를 잠금 비밀번호로 한 번 더 암호화하고, 앱을 켤 때 잠금 화면이 뜹니다.
  • 쓰는 중에도 잠급니다. Ctrl + Alt + L(설정에서 바꿀 수 있음) 또는 자동 잠금(PC 를 5~60분 안 쓰면).
  • 잠겨도 열린 세션은 끊기지 않고 계속 돕니다. 잠긴 동안 외부 AI 도구(MCP) 요청은 기본으로 막습니다.
  • 5회 틀리면 30초 기다립니다.

비밀번호를 잊었다면

  1. 잠금 화면의 [비밀번호를 잊었어요] → 등록해 둔 Google OTP 6자리로 본인 확인.
  2. 지워지는 것을 확인합니다. 저장된 서버 비밀번호·SSH 키·키 암호·저장된 토큰(AI 키·MCP 토큰)이 지워집니다. 서버 이름·주소·계정·그룹과 설정·단축키·세션 기록은 남습니다.
  3. 새 비밀번호를 두 번 넣습니다.
🛡️ OTP 를 등록하지 않았다면 비밀번호를 되찾을 방법이 없습니다. 그때는 아라를 초기화해야 합니다. 미리 OTP 를 등록해 두세요.

이 PC 에서 풀 수 없는 저장 비밀번호로 접속하면 비밀번호를 다시 묻고, 그런 저장값이 있으면 알려 주며 [지우기]를 드립니다.

8. 업데이트

  1. 새 버전이 나오면 알려 줍니다. 설정 › 업데이트 에서 [업데이트 확인]도 됩니다.
  2. [받기]를 누르면 받습니다. 받는 동안에도 하던 일은 그대로 하시면 됩니다.
  3. 설치는 앱을 껐다 켤 때 일어납니다. 바로 하려면 [다시 시작하여 설치].
  4. 끝나면 "ARA 가 ○○ 로 업데이트되었습니다"와 [패치 내역 보기]가 나옵니다.
⚠️ 다시 시작하면 열려 있는 터미널과 SSH 연결은 끊깁니다. AI 작업 공간의 에이전트는 이어집니다(10. 자주 묻는 것).

자동 업데이트는 아라가 켜져 있어야 동작합니다. 앱이 안 켜져서 못 받는 경우에는 다운로드 페이지에서 받아 덮어 설치하세요.

10. 자주 묻는 것

업데이트해도 에이전트가 살아 있는 이유

AI 작업 공간의 에이전트는 앱 창이 아니라 백그라운드(로컬 데몬)에서 돕니다. 그래서 앱을 닫거나 업데이트해도 계속 일하고, 다시 켜면 그 탭이 그대로 이어집니다. (터미널 탭과 SSH 연결은 끊깁니다.) 백그라운드 데몬 자체가 꺼진 경우에는 탭에 "잃음"이 뜨며, 그때는 [지난 세션]에서 이어 하세요.

백신이 설치·실행을 막을 때

  • 다시 시도하지 마세요. 화면을 캡처해 담당자에게 알려 주세요. 예외 처리를 요청합니다.
  • 2.2.1 부터 설치 프로그램은 PowerShell 을 쓰지 않습니다(이전에 보안 제품에 막히던 원인).
  • 2.2.1 설치 후 "Cannot find module" 로 안 켜졌다면 2.2.2 이상을 받아 덮어 설치하세요.

"바뀐 파일이 없습니다"라고 나옵니다

  • 변경 비교는 커밋하지 않은 변경을 보여 줍니다. 에이전트나 편집기가 파일을 고치면 그때 나타납니다.
  • 이미 커밋했다면 "기준 브랜치에서 갈라진 뒤 커밋한 변경" 보기도 있습니다. 거기서 변경이 없다는 뜻일 수 있습니다.
  • 엉뚱한 워크트리를 보고 있지 않은지 탭 줄 앞의 워크트리 칩을 확인하세요(탭 묶음은 워크트리마다 따로입니다).

링크가 Oriel 이 아니라 기본 브라우저로 열립니다

Oriel 을 못 찾은 것입니다. 설정 › 에이전트 › Oriel (웹 도구) 에서 확인하세요.

더 필요하면

서버 접속·파일·RDP 문제는 1.x 설명서 §14. 그래도 안 되면 Ctrl + Shift + F1 로 오류 신고를 남겨 주세요.
